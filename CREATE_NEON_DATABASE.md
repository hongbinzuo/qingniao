# Create Neon Database - Quick Guide

## Step 1: Sign Up (30 seconds)
1. Go to: https://neon.tech
2. Click "Sign up"
3. Choose "Continue with GitHub" (easiest)
4. Authorize Neon

## Step 2: Create Project (30 seconds)
1. Click "Create a project"
2. Name: `abu-scanner`
3. Region: Choose closest to you
4. Click "Create project"

## Step 3: Get Connection String (30 seconds)
1. You'll see "Connection Details" immediately
2. Copy the connection string that looks like:
   ```
   postgresql://user:pass@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require
   ```
3. Save it somewhere safe

## Step 4: Run Setup Script
1. Double-click: `setup_neon_railway.bat`
2. Paste your connection string
3. Done!

Total time: 2 minutes
Cost: FREE forever (0.5GB storage)
