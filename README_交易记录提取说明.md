# 交易记录提取说明

## 功能概述

系统现在支持**从对话中自动提取交易记录**，包括：
- 加仓操作
- 减仓操作
- 滚仓操作序列
- 止盈/止损操作

## 使用方法

### 自动提取

```bash
# 从最近1天的对话中提取交易记录
python src/extract_trades_from_conversations.py --days 1 --auto

# 交互式提取（会显示并确认）
python src/extract_trades_from_conversations.py --days 1
```

### 手动提取特定对话

```python
from extract_trades_from_conversations import TradeExtractor

extractor = TradeExtractor()
trades = extractor.extract_trades_from_conversation(
    conv_id=4681,
    timestamp="2025-12-31 02:43:39",
    message="已经从876加到881了 不过刚刚888减仓一半，883加回1/4"
)
```

## 提取规则

### 支持的格式

1. **向下加仓**: "从876加到881"
   - 提取为：初始入场876，加仓到881

2. **减仓**: "888减仓一半"
   - 提取为：在888减仓

3. **回调加仓**: "883加回1/4"
   - 提取为：在883加仓

4. **单独加仓**: "893加仓"
   - 提取为：在893加仓

### 价格识别

- **简化价格**: 876 → $87,600
- **完整价格**: 87600 → $87,600
- **价格范围**: 400-1000 (简化) 或 40000-150000 (完整)

## 注意事项

1. **时间戳**: 使用对话的时间戳
2. **方向**: 默认做多（long），可根据消息判断
3. **去重**: 自动检查是否已存在，避免重复
4. **关联**: 交易记录关联到原始对话ID

## 数据存储

交易记录存储在 `trade_records` 表：
- `entry_price`: 入场价格（加仓时）
- `exit_price`: 出场价格（减仓时）
- `strategy`: 策略名称（如"滚仓策略"）
- `text_content`: 操作描述
- `source`: 'conversation_extraction'
- `related_conversation_id`: 关联的对话ID
