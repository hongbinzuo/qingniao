# Discord全量导出处理工具

## 快速开始

```bash
# 处理Discord导出文件
python src/process_full_discord_export.py path/to/export.json

# 或处理整个目录
python src/process_full_discord_export.py path/to/export_directory/
```

## 功能

✅ 自动解析Discord导出（JSON/CSV/TXT）  
✅ 自动去重  
✅ 智能分类（观点/交易记录/信号）  
✅ 自动获取BTC价格  
✅ 批量导入数据库
