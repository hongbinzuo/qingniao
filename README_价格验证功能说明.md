# 价格验证功能说明

## 功能概述

系统现在具备**价格验证功能**，能够：
1. 自动验证对话中提到的价格是否合理
2. 结合BTC实时价格数据进行检查
3. 发现可能的输入错误（如818 vs 881）
4. 提供修正建议

## 问题发现

在录入对话时，系统发现了价格验证问题：
- **错误价格**: 818（$81,800）
- **正确价格**: 881（$88,100）
- **问题**: 818价格在2025-12-31 00:00-01:00时间段不存在
- **原因**: 可能是输入错误或拼写错误

## 已实施的改进

### 1. 价格验证器 (`src/price_validator.py`)

**功能**：
- 查询指定时间段的BTC价格范围
- 验证价格是否在合理范围内
- 检测常见的输入错误
- 提供修正建议

**使用示例**：
```python
from price_validator import PriceValidator

validator = PriceValidator()

# 验证价格
is_valid, error = validator.validate_price(81800, '2025-12-31 00:23:00')
if not is_valid:
    print(error)  # 会显示价格不在合理范围内

# 建议修正
suggested = validator.suggest_correction(81800, '2025-12-31 00:23:00')
if suggested:
    print(f"建议修正为: ${suggested:,.0f}")  # 88100
```

### 2. 对话录入增强 (`src/add_de_conversation.py`)

**新增功能**：
- 自动验证对话中提到的所有价格
- 发现不合理价格时显示警告
- 提供修正建议
- **不阻止录入**（仅警告，由用户决定）

**警告示例**：
```
⚠️ 价格验证警告:
❌ 价格 $81,800 不在合理范围内！
   时间: 2025-12-31 00:23:00
   实际价格范围: $88,000 - $89,000
   建议检查是否为输入错误
   建议修正为: $88,100
```

## 使用流程

### 1. 录入对话时自动验证

```bash
python src/add_de_conversation.py "0:23" "已经从876加到881了"
```

系统会自动：
1. 提取价格（876, 881）
2. 查询该时间段的BTC价格范围
3. 验证价格是否合理
4. 如有问题，显示警告和建议

### 2. 手动验证价格

```python
from price_validator import PriceValidator

validator = PriceValidator()

# 获取价格范围
price_range = validator.get_price_range('2025-12-31 00:23:00')
print(f"价格范围: ${price_range[0]:,.0f} - ${price_range[1]:,.0f}")

# 验证价格
is_valid, error = validator.validate_price(88100, '2025-12-31 00:23:00')
```

## 常见错误检测

系统能够检测以下常见错误：

1. **数字顺序错误**: 818 vs 881
2. **少一位数字**: 81 vs 881
3. **多一位数字**: 8810 vs 881
4. **价格超出范围**: 价格不在该时间段的实际范围内

## 修正已录入的错误

如果发现已录入的对话包含错误价格，可以使用修正脚本：

```bash
python correct_conversation_price.py
```

这会：
1. 查找包含818的对话
2. 将818替换为881（仅替换独立的数字）
3. 更新数据库记录

## 注意事项

1. **价格验证需要价格数据**: 需要`btc_price_timeseries.duckdb`数据库存在
2. **验证范围**: 默认查询对话时间前后2小时的价格范围
3. **容忍度**: 允许5%的价格偏差（考虑数据延迟等因素）
4. **不阻止录入**: 验证失败时只显示警告，不阻止录入（由用户决定）
