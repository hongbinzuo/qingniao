# 添加运行/休息机制说明

## 功能说明

为了减轻电脑持续运行的压力，添加了**"运行3小时，休息1小时"**的自动机制。

### 机制详情

**工作模式**:
- **运行时长**: 3小时
- **休息时长**: 1小时
- **循环**: 运行3小时 → 休息1小时 → 运行3小时 → ...

**实现位置**: `src/abu/gemini_vision_analyzer.py` 的 `analyze_all` 方法中

### 工作原理

1. **记录运行开始时间**: 每个运行周期开始时记录 `session_start_time`
2. **检查运行时长**: 每处理一张图片前，检查是否已运行满3小时
3. **自动暂停**: 达到3小时后：
   - 保存当前状态（确保数据不丢失）
   - 记录当前进度
   - 开始1小时休息
4. **休息倒计时**: 
   - 每5分钟输出一次剩余时间
   - 最后1分钟内每分钟输出
   - 支持 Ctrl+C 中断（状态已保存）
5. **自动恢复**: 休息结束后自动开始新的运行周期

## 使用说明

### 自动生效

**当前正在运行的进程**: 
- 如果是从旧版本启动的，需要重启才能生效
- 建议：等待当前进程自然触发或手动重启

### 重启方法

如果需要立即生效：

```bash
# 1. 停止当前进程（不会丢失数据，状态已保存）
Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*abu_optimize_speed*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

# 2. 重新启动（会自动从断点继续）
python scripts/abu_optimize_speed.py
```

### 自定义时间

如果需要修改运行/休息时间，可以在代码中修改：

```python
WORK_DURATION_HOURS = 3.0  # 修改为其他值，如 2.5（2.5小时）
REST_DURATION_HOURS = 1.0  # 修改为其他值，如 0.5（30分钟）
```

## 优势

1. ✅ **保护电脑**: 避免持续运行造成硬件压力
2. ✅ **自动管理**: 无需人工干预，自动暂停和恢复
3. ✅ **状态保存**: 暂停前自动保存状态，不会丢失进度
4. ✅ **断点续传**: 支持中断后继续，与现有机制完美兼容
5. ✅ **可中断**: 休息期间可以 Ctrl+C 中断并立即继续处理

## 注意事项

1. ⚠️ **当前运行进程**: 如果是从旧代码启动的，需要在下次启动时才能生效
2. ⚠️ **时间计算**: 运行时间从当前运行周期开始计算，不是从程序启动时
3. ⚠️ **休息期间**: 程序仍在运行（在休息循环中），不是完全停止
