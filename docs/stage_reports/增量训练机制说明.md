# 增量训练机制说明

## 📋 概述

价格行为特征学习模型支持增量训练机制：
- **首次训练**：使用当前可用的所有数据（目前429条，完整版约9000+条）
- **增量训练**：当数据量增加10%以上时，自动触发重新训练
- **自动触发**：集成到Gemini处理流程管理器，自动检测并触发
- **完整数据规模**：约9000+条记录（完整版）

## 🔄 工作机制

### 1. 训练触发条件

增量训练在以下情况下触发：

1. **首次训练**：模型文件不存在时
2. **增量训练**：数据量增加10%以上时
   - 上次训练样本数：N
   - 当前数据量：M
   - 触发条件：M >= N * 1.1

### 2. 训练流程

```
数据库更新完成
    ↓
检查数据量变化
    ↓
是否需要训练？
    ├─ 是 → 检查是否有已训练模型
    │       ├─ 有 → 增量训练（使用所有数据重新训练）
    │       └─ 无 → 首次训练
    └─ 否 → 跳过
    ↓
训练模型
    ↓
保存模型和状态
```

### 3. 模型状态跟踪

模型状态保存在 `models/abu/price_action_model_state.json`：

## 🚀 使用方式

### 1. 手动训练

```bash
# 首次训练
python src/ml_dl/abu_price_action_learner.py --train

# 增量训练
python src/ml_dl/abu_price_action_learner.py --retrain

# 检查是否需要重新训练
python src/ml_dl/abu_price_action_learner.py --check
```

### 2. 自动训练（集成到处理流程）

增量训练已集成到Gemini处理流程管理器：

```bash
# 运行处理流程（自动检测并触发增量训练）
python scripts/abu_gemini_pipeline_manager.py

# 轮询模式（每4小时自动运行，包含增量训练）
python scripts/abu_gemini_pipeline_manager.py --poll --interval 4
```

### 3. 训练时机

- **首次训练**：完成数据库更新后，立即训练（使用当前可用数据，目前429条）
- **增量训练**：
  - 数据量增加10%以上时自动触发
  - 轮询模式每4小时检查一次
  - 完整版数据规模：约9000+条记录

## 📊 训练数据

### 数据来源

- **数据表**：`pattern_library`
- **字段**：`gemini_annotation_json`
- **过滤条件**：`gemini_annotation_json IS NOT NULL AND gemini_annotation_json != ''`

### 特征提取

从Gemini分析结果提取特征：
- 模式特征（pattern_count, has_reversal_pattern等）
- K线特征（has_engulfing, has_pin_bar等）
- 交易信号特征（signal_count, avg_probability等）
- 趋势特征（trend_bullish, trend_bearish等）

### 标签生成

从模式类型推断价格行为标签：
- **reversal**：包含reversal类型的模式
- **continuation**：包含continuation类型的模式
- **consolidation**：包含consolidation类型的模式
- **indecision**：其他情况

## ⚠️ 注意事项

1. **依赖库**：需要安装 xgboost 和 scikit-learn
   ```bash
   pip install xgboost scikit-learn numpy
   ```

2. **数据量**：目前只有429条记录，完整版约9000+条记录。可以先用现有数据训练，随着数据增加自动增量训练

3. **增量训练**：XGBoost不支持真正的增量训练，所以增量训练实际上是使用所有数据重新训练

4. **训练时间**：训练时间取决于数据量和模型参数，通常几秒到几分钟

5. **自动触发**：增量训练在数据更新完成后自动触发，无需手动干预
