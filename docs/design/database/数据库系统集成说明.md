# 数据库系统集成说明

## ✅ 已完成的功能

### 1. 多数据库支持
- ✅ **DuckDB** (默认推荐) - 高性能，无需服务器
- ✅ **MySQL** - 支持已有MySQL环境
- ✅ **SQLite** - 备选方案
- ✅ 通过配置文件轻松切换

### 2. De.观点自动识别
- ✅ 自动识别带"De."标记的内容
- ✅ 支持多种格式：
  - `De.说：...`
  - `De.观点：...`
  - `De.指令：...`
  - `De.原话：...`
  - `"De. ..."`
  - `De. ...`

### 3. 对话日志记录
- ✅ 自动记录所有对话
- ✅ 标记是否包含De.内容
- ✅ 自动提取De.观点到数据库

### 4. 自动清理
- ✅ 保留最近3个月的日志
- ✅ 可配置保留天数

## 🚀 快速开始

### 1. 安装数据库（推荐DuckDB）

```bash
pip install duckdb
```

### 2. 初始化数据库

```bash
python src/database_setup.py
```

### 3. 使用对话记录器

```python
from src.conversation_logger import log_conversation

# 记录对话（自动提取De.观点）
log_id, de_contents = log_conversation(
    user_message="De.说：明天低多，多在863下面损一次",
    assistant_message="好的，已记录"
)

if de_contents:
    print(f"提取到 {len(de_contents)} 条De.观点")
```

## 📊 数据库结构

### de_viewpoints 表
- `id` - 主键
- `content` - 观点内容
- `timestamp` - De.说的时间
- `source` - 来源（manual/conversation/dialog）
- `category` - 类别（trading/analysis/instruction）
- `tags` - 标签（JSON格式）
- `created_at` - 创建时间
- `updated_at` - 更新时间

### conversation_logs 表
- `id` - 主键
- `session_id` - 会话ID
- `user_message` - 用户消息
- `assistant_message` - 助手回复
- `timestamp` - 时间戳
- `has_de_marker` - 是否包含De.标记
- `de_content` - 提取的De.内容
- `created_at` - 创建时间

## 🔧 配置

### 使用DuckDB（默认）

无需配置，直接使用：
```python
from src.db_config import get_db_manager
db = get_db_manager()
```

### 使用MySQL

1. 安装MySQL连接器：
```bash
pip install mysql-connector-python
```

2. 设置环境变量：
```bash
export MYSQL_HOST=localhost
export MYSQL_PORT=3306
export MYSQL_USER=root
export MYSQL_PASSWORD=your_password
export MYSQL_DATABASE=qingniao
export QINGNIAO_DB_TYPE=mysql
```

或编辑 `src/db_config.py` 中的 `MYSQL_CONFIG`

## 📝 使用示例

### 示例1: 手动添加De.观点

```python
from src.db_config import get_db_manager

db = get_db_manager()
db.add_de_viewpoint(
    content="明天低多，多在863下面损一次，85附近再多一次，新低止损",
    timestamp="2025-12-28 01:53:00",
    source="manual",
    category="instruction"
)
```

### 示例2: 查询De.观点

```python
from src.db_config import get_db_manager

db = get_db_manager()

# 获取最近10条观点
viewpoints = db.get_de_viewpoints(limit=10)

# 搜索包含"止损"的观点
results = db.search_de_viewpoints("止损", limit=20)

# 获取指定时间范围的观点
viewpoints = db.get_de_viewpoints(
    start_date="2025-12-01",
    end_date="2025-12-31"
)
```

### 示例3: 查看统计信息

```python
from src.db_config import get_db_manager

db = get_db_manager()
stats = db.get_stats()

print(f"总观点数: {stats['total_viewpoints']}")
print(f"手工录入: {stats['manual_viewpoints']}")
print(f"总日志数: {stats['total_logs']}")
print(f"包含De.的日志: {stats['logs_with_de']}")
```

### 示例4: 清理旧日志

```bash
# 清理90天前的日志
python src/cleanup_old_logs.py
```

## 🔄 自动记录流程

1. **用户发送消息** → 对话记录器捕获
2. **检测De.标记** → 自动提取De.内容
3. **记录对话日志** → 保存到数据库
4. **提取De.观点** → 自动添加到观点表
5. **定期清理** → 保留最近3个月
