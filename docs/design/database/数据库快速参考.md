# 数据库快速参考

## 📁 数据库文件位置

```
src/data/
├── qingniao_shared.duckdb    # 共享数据库（交易员信息）
├── qingniao_de.duckdb        # De.的数据库
└── qingniao_meng.duckdb      # 梦的数据库
```

## 🔍 快速查询

### Python代码

```python
from db_manager_trader import TraderDBManager

# 查询De.的观点
db = TraderDBManager('de')
viewpoints = db.get_viewpoints(limit=10)
db.close()
```

### SQL查询

```sql
-- 连接数据库
ATTACH 'data/qingniao_de.duckdb' AS de_db;

-- 查询观点
SELECT * FROM de_db.trader_viewpoints LIMIT 10;

-- 查询交易记录
SELECT * FROM de_db.trade_records ORDER BY timestamp DESC;

-- 查询信号
SELECT * FROM de_db.trading_signals WHERE status = 'pending';
```

## 📊 表结构速查

### conversations - 对话记录
- `id`, `timestamp`, `user_message`, `trader_message`
- `source`, `has_trading_info`, `extracted_content`, `btc_price`

### trade_records - 交易记录
- `id`, `timestamp`, `symbol`, `direction`, `leverage`
- `entry_price`, `exit_price`, `profit_pct`, `profit_usdt`
- `screenshot_path`, `text_content`, `source`

### trader_viewpoints - 交易观点
- `id`, `content`, `timestamp`, `source`, `category`, `tags`
- `btc_price`, `related_trade_id`, `related_conversation_id`

### trading_signals - 交易信号
- `id`, `signal_time`, `timeframe`, `signal_type`
- `entry_price`, `stop_loss`, `take_profit_1`, `take_profit_2`
- `entry_model`, `strength`, `risk_reward_ratio`, `status`

### signal_evaluations - 信号评估
- `id`, `signal_id`, `evaluation_time`, `result`
- `actual_profit_pct`, `stop_loss_hit`, `take_profit_1_hit`

### strategy_rules - 策略规则（可选）
- `id`, `rule_name`, `rule_type`, `rule_content`, `parameters`, `enabled`
