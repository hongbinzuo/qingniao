## 📊 数据库结构

### 主数据库表

1. **de_viewpoints** - De.观点表
   - 存储所有De.的观点和交易指令
   - 包含BTC价格、标签、分类等
   - 当前数据: 15条

2. **conversation_logs** - 对话日志表
   - 存储最近3个月的对话记录
   - 自动标记是否包含De.内容
   - 当前数据: 0条（对话日志通过观点表存储）

3. **trade_records** - 交易记录表
   - 存储De.的交易记录
   - 包含盈亏、杠杆等信息
   - 当前数据: 0条（交易记录通过观点表存储）

### 归档数据库表

- `de_viewpoints_archive` - 归档的De.观点
- `conversation_logs_archive` - 归档的对话日志（3个月以上）
- `trade_records_archive` - 归档的交易记录

## 🔄 分库分表策略

### 当前阶段（推荐）

**单库双表策略**:
- **主数据库**: 当前数据（最近3个月）
- **归档数据库**: 历史数据（3个月以上）

**数据量估算**:
- 3年内数据量: 约16,600-36,500条
- 单表存储完全足够
- **不需要分表**
