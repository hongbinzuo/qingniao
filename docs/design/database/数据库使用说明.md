# 数据库使用说明

## 🎯 推荐方案

### **DuckDB** ⭐⭐⭐⭐⭐ (默认推荐)

**为什么选择DuckDB**:
- ✅ 性能优秀（比SQLite快10-100倍）
- ✅ 无需安装数据库服务器
- ✅ 支持完整SQL语法
- ✅ 单文件数据库，易于备份
- ✅ 适合数据分析场景

**安装**:
```bash
pip install duckdb
```

**使用**:
```python
from src.db_config import get_db_manager

db = get_db_manager()  # 自动使用DuckDB
```

---

## 📦 其他方案

### MySQL

**适用场景**: 已有MySQL环境、需要远程访问

**安装**:
```bash
# 安装MySQL连接器
pip install mysql-connector-python

# 或使用PyMySQL
pip install pymysql
```

**配置**:
```bash
# 设置环境变量
export MYSQL_HOST=localhost
export MYSQL_PORT=3306
export MYSQL_USER=root
export MYSQL_PASSWORD=your_password
export MYSQL_DATABASE=qingniao
export QINGNIAO_DB_TYPE=mysql
```

**或编辑 `src/db_config.py`**:
```python
MYSQL_CONFIG = {
    'host': 'localhost',
    'port': 3306,
    'user': 'root',
    'password': 'your_password',
    'database': 'qingniao',
    'charset': 'utf8mb4'
}
```

## 🔧 切换数据库类型

### 方法1: 环境变量
```bash
# Windows
set QINGNIAO_DB_TYPE=mysql

# Linux/Mac
export QINGNIAO_DB_TYPE=mysql
```

### 方法2: 修改配置文件
编辑 `src/db_config.py`:
```python
DB_TYPE = 'mysql'  # 改为 'duckdb', 'mysql', 'sqlite', 'tinydb'
```

## 🚀 快速开始

### 1. 安装DuckDB（推荐）
```bash
pip install duckdb
```

### 2. 初始化数据库
```bash
python src/database_setup.py
```

### 3. 使用数据库
```python
from src.db_config import get_db_manager

db = get_db_manager()

# 添加De.观点
db.add_de_viewpoint(
    content="De.说：明天低多",
    timestamp="2025-12-30 10:30:00",
    source="conversation",
    category="trading"
)

# 查询观点
viewpoints = db.get_de_viewpoints(limit=10)
```

## 🔒 安全建议

### DuckDB
- ✅ 单文件，可以加密备份
- ✅ 设置文件权限（仅用户可读写）

### MySQL
- ✅ 使用强密码
- ✅ 限制访问IP
- ✅ 定期备份
