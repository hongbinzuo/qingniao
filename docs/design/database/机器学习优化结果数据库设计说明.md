## 📊 数据库设计

### ml_optimization_results 表

**用途**: 存储所有机器学习优化操作的结果，方便查询和分析优化历史

**字段说明**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键 |
| optimization_type | TEXT | 优化类型（见下方说明） |
| optimization_time | TEXT | 优化时间（ISO格式） |
| status | TEXT | 状态（completed/failed/in_progress） |
| data_count | INTEGER | 使用的数据量（已完成信号数、评估数据数等） |
| time_span_days | INTEGER | 数据时间跨度（天） |
| metrics_json | TEXT | JSON格式的性能指标 |
| parameters_before | TEXT | JSON格式的优化前参数 |
| parameters_after | TEXT | JSON格式的优化后参数 |
| improvements_json | TEXT | JSON格式的改进建议 |
| model_file_path | TEXT | 模型文件路径（如果有） |
| report_file_path | TEXT | 报告文件路径（如果有） |
| notes | TEXT | 备注 |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

**索引**:
- `idx_ml_optimization_type` - 优化类型索引
- `idx_ml_optimization_time` - 优化时间索引

## 🎯 优化类型说明

### 1. incremental_learning（增量学习）

**说明**: 使用最新数据更新模型参数

**典型场景**:
- 每10条已完成信号自动触发
- 每周优化

**记录内容**:
- `data_count`: 使用的信号数（如10-50条）
- `metrics`: 性能指标（胜率、平均收益等）
- `parameters_before/after`: 参数变化（止损倍数、止盈倍数等）
- `improvements`: 改进建议

### 2. ml_training（ML模型训练）

**说明**: 训练新的机器学习模型

**典型场景**:
- 数据量达到50条时首次训练
- 数据量达到100条时重新训练

**记录内容**:
- `data_count`: 训练数据量
- `metrics`: 模型性能（准确率、胜率等）
- `model_file_path`: 模型文件路径
- `report_file_path`: 训练报告路径

### 3. full_retrain（完整模型重训练）

**说明**: 使用所有历史数据重新训练模型

**典型场景**:
- 每月1号自动触发
- 模型性能下降时触发

**记录内容**:
- `data_count`: 使用的总数据量
- `metrics`: 新模型性能指标
- `parameters_before/after`: 模型参数变化
- `model_file_path`: 新模型文件路径

### 4. parameter_optimization（参数优化）

**说明**: 通过回测优化交易参数

**典型场景**:
- 回测优化止损/止盈倍数
- 优化目标盈亏比

**记录内容**:
- `data_count`: 回测使用的信号数
- `metrics`: 回测结果（胜率、收益率、最大回撤等）
- `parameters_before/after`: 参数变化
- `improvements`: 优化建议

### 5. pattern_weight_optimization（模式权重优化）

**说明**: 根据历史表现优化模式权重

**典型场景**:
- 每月优化一次模式权重

**记录内容**:
- `data_count`: 使用的信号数
- `metrics`: 优化后的性能指标
- `parameters_before/after`: 权重变化

## 📝 使用方式

### 1. 记录优化结果

```python
from ml_dl.optimization_result_recorder import OptimizationResultRecorder

recorder = OptimizationResultRecorder('abu')

# 记录增量学习结果
recorder.record_incremental_learning(
    data_count=25,
    time_span_days=3,
    metrics={'win_rate': 45.5, 'avg_profit': 0.8},
    parameters_before={'stop_loss_multiplier': 1.0},
    parameters_after={'stop_loss_multiplier': 1.2},
    improvements=['增加止损距离', '提高盈亏比']
)

recorder.close()
```

### 2. 查询优化历史

```python
from ml_dl.optimization_result_recorder import OptimizationResultRecorder

recorder = OptimizationResultRecorder('abu')

# 获取最近的10条记录
history = recorder.get_optimization_history(limit=10)

# 获取特定类型的记录
history = recorder.get_optimization_history(
    optimization_type='incremental_learning',
    limit=5
)

recorder.close()
```

### 3. 使用命令行查询

```bash
# 查询最近的优化结果
python scripts/query_ml_optimization_results.py

# 查询特定类型的优化结果
python scripts/query_ml_optimization_results.py --type incremental_learning

# 只显示最新的
python scripts/query_ml_optimization_results.py --latest

# 限制返回数量
python scripts/query_ml_optimization_results.py --limit 20
```

## 🔍 查询示例

### 查询所有增量学习记录

```python
from db_manager_trader import TraderDBManager

db = TraderDBManager('abu')
results = db.get_ml_optimization_results(
    optimization_type='incremental_learning',
    limit=10
)

for result in results:
    print(f"时间: {result['optimization_time']}")
    print(f"数据量: {result['data_count']} 条")
    # 解析JSON字段
    import json
    metrics = json.loads(result['metrics_json'])
    print(f"胜率: {metrics.get('win_rate', 0):.1f}%")
```

    print(f"胜率: {metrics.get('win_rate', 0):.1f}%")

系统会在以下情况自动记录优化结果：

- ✅ ML模型训练完成后
- ✅ 完整模型重训练完成后
- ✅ 参数优化完成后
- ✅ 模式权重优化完成后

### 手动查询

使用 `scripts/query_ml_optimization_results.py` 脚本可以方便地查询历史记录。

### 数据清理

建议保留最近6个月的优化记录，更早的记录可以归档或删除：

```python
from db_manager_trader import TraderDBManager
from datetime import datetime, timedelta

db = TraderDBManager('abu')
conn = db._get_connection()

# 删除6个月前的记录
cutoff_date = (datetime.now() - timedelta(days=180)).strftime('%Y-%m-%d')
conn.execute('''
    DELETE FROM ml_optimization_results 
    WHERE optimization_time < ?
''', (cutoff_date,))
conn.commit()
```

## 🔧 故障处理

### 表不存在

如果表不存在，系统会自动创建。如果创建失败，可以手动运行：

```python
from database_design_v2 import DatabaseDesignV2

design = DatabaseDesignV2()
design.create_trader_database('abu', 'Abu')
```

### 查询失败

如果查询失败，检查：
1. 数据库文件是否存在
2. 表结构是否正确
3. 字段名是否匹配
