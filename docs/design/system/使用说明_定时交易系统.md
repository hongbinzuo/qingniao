# 定时交易系统使用说明

## 当前配置

- **运行间隔**: 每4小时自动运行一次
- **输出目录**: `trading_signals\` （所有生成的文件都在这里）
- **休眠策略**: 休眠后需要手动启动脚本

## 快速开始

### 启动定时运行

**方法1：使用批处理文件（推荐）**
```
双击运行: 启动定时交易系统.bat
```

**方法2：命令行**
```bash
python src/unified_trading_system.py --system all --interval 4
```

### 系统更新后重启

**方法1：使用批处理文件**
```
双击运行: 重启定时交易系统.bat
```

**方法2：手动重启**
1. 按 `Ctrl+C` 停止当前运行的程序
2. 双击运行 `启动定时交易系统.bat`

### Windows休眠后

**休眠后需要手动启动**：
```
双击运行: 启动定时交易系统.bat
```

## 输出文件位置

所有生成的文件都保存在 `trading_signals\` 目录：

- **De.系统文件**: `BTC_de_signals_YYYYMMDD_HHMMSS.md`
- **梦多空策略文件**: `梦多空策略_交易计划_YYYYMMDD_HHMMSS.md`

## 查看最新文件

### Windows PowerShell
```powershell
# 进入输出目录
cd trading_signals

# 查看最新的De.系统文件
Get-ChildItem -Filter "BTC_de_signals*.md" | Sort-Object LastWriteTime -Descending | Select-Object -First 1

# 查看最新的梦多空策略文件
Get-ChildItem -Filter "梦多空策略*.md" | Sort-Object LastWriteTime -Descending | Select-Object -First 1
```

## 停止程序

在运行窗口中按 `Ctrl+C` 即可停止。

## 注意事项

1. **休眠问题**: Windows休眠会停止程序运行，唤醒后需要手动启动
2. **系统更新**: Windows更新重启后，需要手动启动程序
3. **输出目录**: 所有文件都在 `trading_signals\` 目录，不在根目录
4. **运行间隔**: 每4小时运行一次，首次运行会立即执行一次
