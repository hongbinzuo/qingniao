# 系统设计演进（青鸟·De.交易系统）

## 背景
- De. 以“位置 + 结构 + 失效线 + 保本”为核心的主观交易，短线胜率高，但需要看盘。
- 目标：系统化复制其“好位置与高赔率”的方法，形成可评估、可学习的闭环。

## 里程碑
- M0：官方生成器雏形（`generate_btc_de_signals.py`）
  - 问题：输出较多、位置泛化、评估节奏不稳。
- M1：风格筛选器（`scripts/generate_style_filtered_signals.py`）
  - 条件：RR≥阈值（现为2.0）、排除突破、入场偏差≤0.3%
  - 输出：简要/详细版 + 技术分析块
- M2：Falcon 守护与状态
  - 每小时生成；严格检查返回码、记录 `last_errors/last_files`，简报式状态脚本
  - 修复：去除 DB 长时持锁，录入不再需要重启 Falcon
- M3：战术指引与信心标记
  - 固化 De. 的“回撤区 + 动态 SR → 空，强穿回踩 → 多”的作战规则
  - 信心标记（A/B/C/D）与线索输出
- M4：动态 SR 与情绪聚合
  - `sr_detector.py`：swing + 网格聚类 + 多周期合并，替代固定数值（如“883”）
  - `sentiment_aggregator.py`：Fear&Greed、Coinbase 溢价、Binance 多空比、Funding
- M5：技术归因与学习归档
  - `label_de_trades_techniques.py`：为最近实盘自动打标签（OTE/动态SR/Vegas/VWAP/883一致），写入观点与学习报告
  - 评估规则：仅评估“未评估且>24h”的信号，产出评估报告并更新参数

## 关键设计决策
- “位置先行”：不追突破，只做 0.618/0.786 回撤区与动态 SR 邻近的高赔率位置
- “失效线明确”：强穿→翻多/翻空；报告输出“失效线/保本/移动止盈”的模板
- “多周期一致”：1h/15m 同向时信号优先；5m 仅作触发
- “逆向情绪”：使用公开端点聚合情绪，作为信心加权因子（逐步校准）
- “慢评估、勤产出”：生成每小时；评估延迟≥24h，避免噪音干扰

## 技术要点
- 动态 SR（`sr_detector.py`）
  - Fractal swings（窗口5）提取拐点 → 价格网格聚类（50$步长） → 触发次数+新近加权 → Top-N 支撑/阻力
  - 多周期合并，形成更稳的 SR 区
- 情绪聚合（`sentiment_aggregator.py`）
  - Fear&Greed、Coinbase 溢价、Binance 长短比、Funding → 线性映射至 -100~+100
- 信心标记
  - 因素：OTE/动态 SR/EMA 一致性/形态（+情绪加权预留）
  - 等级/概率：A≈68%、B≈58%、C≈50%、D≈45%（后续用 Isotonic/Platt 校准）
- 守护可靠性
  - 每轮内部开关 DB；状态记录错误与产出；Windows/Linux 双栈脚本

## 风险与权衡
- 公开端点的可用性与限流（已容错），SR 步长与窗口需要因市调参
- 概率尚未校准：需要影子交易统计 + Isotonic/Platt 校准
- 组合胜率需要分场景统计（趋势/震荡、波动率、情绪极值）

## 未来计划
- 概率校准：收集影子交易数据，使用 `sklearn` 做校准，输出置信区间
- 组合统计：生成“最近20/50笔技术组合胜率”快照并展示在报告尾部
- OI/成交量流向：引入更多公开/低门槛数据源用于情绪和拥挤度识别
- 自动化执行策略模板：在简要版直接给出“空/多”模板化下单参数（入场、止损、保本、分批止盈）
- UI 与看板：将 `last_errors/last_files` 与统计结果汇总到 Web/Notebook 看板
