## 🚀 使用方法

### 1. 直接运行分析脚本

```bash
# 分析突破873规则
python analyze_with_breakout_rule.py

# 或使用简化版分析
python analyze_breakout_873.py
```

### 2. 使用规则引擎

```python
from simple_rules_engine import analyze_with_rules_engine

# 准备市场数据
market_data = {
    'current_price': 87000,
    'ema_144': 86800,
    'ema_169': 86900,
    'timeframe': '15m'
}

# 添加突破位（De.规则：这把上去突破873可以进）
breakout_levels = [87300]

# 运行规则引擎
signals = analyze_with_rules_engine(
    market_data=market_data,
    breakout_levels=breakout_levels
)

# 查看信号
for signal in signals:
    print(f"{signal.rule_name}: {signal.signal_type} @ ${signal.entry:.2f}")
```
