## 🎯 系统特点

### 明确的交易规则

1. **第一步：市场分析**
   - 识别震荡区间
   - 确定区间上下沿
   - 区间宽度要求：至少200-500点

2. **第二步：入场规则**
   - 区间挂单法（推荐）
   - 回踩入场法
   - M顶/W底入场法

3. **第三步：止损规则**
   - 假突破保护原则
   - 流动性区域外原则
   - 止损距离：几百点
   - 逐仓模式 + 杠杆计算

4. **第四步：止盈规则**
   - 区间上下沿止盈
   - 区间中间止盈
   - 打掉低点/高点止盈
   - 分批止盈

5. **第五步：仓位管理**
   - 仓位大小：100油账户，每次10-20油
   - 盈亏比要求：固定2倍以上

## ✅ 交易前检查清单

每次交易前必须确认：

1. ✅ 已识别明确的震荡区间
2. ✅ 区间宽度足够（至少200点）
3. ✅ 已确定入场位置（区间上下沿）
4. ✅ 已设置止损（假突破不能打到）
5. ✅ 已设置止盈（2倍以上盈亏比）
6. ✅ 已计算仓位大小（风险不超过5%）
7. ✅ 已使用逐仓模式
8. ✅ 已挂单（不追价）
9. ✅ 确认不是单边行情
10. ✅ 盈亏比≥2倍

**只有所有项目都确认后，才能执行交易！**

## 🚨 必须遵守的规则

1. **严格止损** - 止损是生命线
2. **单边行情回避** - 震荡能赚，单边死亏
3. **区间失效处理** - 突破后重新识别新区间
4. **不要追涨杀跌** - 必须挂单等待
5. **盈亏比不足不交易** - 宁可错过，不要做错
