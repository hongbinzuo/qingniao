## 🎯 核心指标系统（新增内容）

### 1. Vegas通道系统（核心）

**定义**: EMA144 + EMA169

**实际使用方法**（基于De.的真实案例）：
- **识别区间**: 价格在Vegas通道内 = 震荡区间
- **判断支撑阻力**: 
  - 价格在通道上方 = 通道作为支撑
  - 价格在通道下方 = 通道作为阻力（压制）
- **确认交易区间**: 区间上下沿需要Vegas通道确认
- **与VWAP结合**: Vegas通道确定边界，VWAP确认支撑阻力位置

**实际案例**：
- "目前价格在864-882区间，15分vegas压制（87127-87400），15分vwap支撑862"
- "15分走楔形牛旗，支撑91000阻力93300，vwap92625 vegas92560-92636"
- "vegas是参考，我一般用支撑阻力线，如果重合就绝杀"

### 2. VWAP系统

**作用**：
- 确认支撑阻力（动态）
- 与Vegas通道结合使用
- 不同时间框架的VWAP（5分钟、15分钟、1小时）

**实际案例**：
- "现在五分钟vwap压制，偏空"
- "目前震荡区间1069-108，刚刚测试了vwap(1082)"
- "15分vwap支撑862"

### 3. RSI指标系统（De.的实际经验）

**重要发现**（De.的总结）：
1. RSI > 50 与下跌趋势：一般跌不动，横盘或跌少涨多
2. RSI < 50 与上涨趋势：一般涨不动，横盘或涨少跌多
3. 单边行情：RSI顶着顶格跑，指标钝化
4. **局限性**：震荡能赚，单边死亏，最后还是看趋势

## 📊 完整的交易流程（包含指标）

### 第一步：设置图表指标
- EMA144（Vegas通道）
- EMA169（Vegas通道）
- VWAP（对应时间框架）
- RSI（可选）
- 斐波那契回撤工具（618-786）

### 第二步：识别交易区间
- 观察价格在EMA144和EMA169之间的震荡
- 用VWAP确认支撑阻力位置
- 区间宽度至少200-500点

### 第三步：判断支撑阻力
- **支撑位**: 区间下沿（EMA144）+ VWAP + 大周期EMA144
- **阻力位**: 区间上沿（EMA169）+ VWAP + 大周期EMA169

### 第四步：入场规则（结合指标）
- **多单**: 价格回落到区间下沿 + VWAP支撑 + 大周期趋势向上
- **空单**: 价格反弹到区间上沿 + VWAP阻力 + 大周期趋势向下

### 第五步：止损止盈（结合指标）
- **止损**: 假突破不能打到 + 参考VWAP + 不破大周期EMA
- **止盈**: 区间上下沿 + 参考VWAP + 分批止盈
