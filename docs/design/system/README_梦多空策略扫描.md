# 梦多空策略 - 涨幅榜扫描功能使用说明

## 功能概述

本脚本实现了梦多空策略的自动化扫描功能，每2小时扫描一次涨幅榜，筛选符合做空和做多条件的币种，并生成详细的交易计划。

## 功能特点

1. **多交易所支持**: 支持Bitget、Bybit、Binance三个交易所
2. **自动切换**: 自动选择可用的交易所（优先顺序：Bitget → Bybit → Binance）
3. **智能筛选**: 
   - 做空：24小时涨幅 > 20%
   - 做多：24小时涨幅在 8%-12% 之间
4. **技术分析**: 自动计算斐波那契扩展位（做空策略）
5. **详细计划**: 生成包含入场价、止损价、止盈策略的完整交易计划
6. **定时扫描**: 支持每N小时自动扫描

## 使用方法

### 基本使用

```bash
# 扫描一次（默认扫描前100个币种）
python src/scan_meng_duo_kong_strategy.py

# 指定交易所
python src/scan_meng_duo_kong_strategy.py --exchange bitget

# 指定扫描币种数
python src/scan_meng_duo_kong_strategy.py --limit 50

# 每2小时自动扫描（默认）
python src/scan_meng_duo_kong_strategy.py --interval 2

# 每4小时自动扫描
python src/scan_meng_duo_kong_strategy.py --interval 4
```

### 命令行参数

- `--exchange`: 选择交易所（auto/bitget/bybit/binance），默认：auto
- `--limit`: 扫描币种数，默认：100
- `--interval`: 周期性扫描间隔（小时），默认：2，设为0表示只扫描一次

### 示例

```bash
# 示例1：扫描一次，使用Bitget，扫描前50个币种
python src/scan_meng_duo_kong_strategy.py --interval 0 --exchange bitget --limit 50

# 示例2：每2小时自动扫描，使用Bybit
python src/scan_meng_duo_kong_strategy.py --interval 2 --exchange bybit

# 示例3：每6小时自动扫描，扫描前200个币种
python src/scan_meng_duo_kong_strategy.py --interval 6 --limit 200
```

梦多空策略_交易计划_YYYYMMDD_HHMMSS.md

文件名格式：`梦多空策略_交易计划_日期_时间.md`

## 交易计划内容

### 做空计划包含：

1. **基本信息**
   - 当前价格
   - 24小时涨幅
   - 日线低点和高点

2. **斐波那契扩展位**
   - 1.618扩展位
   - 2.0扩展位
   - 入场区间（1.618-2.0扩展位，允许±2%容差）

3. **交易计划**
   - 入场区间
   - 止损价（入场价上方2%）
   - 止盈策略（分批止盈：50%/100%/200%）
   - 持仓时间（第二天上午到下午2点）

### 做多计划包含：

1. **基本信息**
   - 当前价格
   - 24小时涨幅
   - 24小时高点

2. **交易计划**
   - 入场价（追涨入场）
   - 止损价（从高点下跌7%）
   - 止盈策略（20%开始分批止盈）
   - 持仓时间（不限定日内）

## 策略规则

### 做空策略

- **筛选条件**: 24小时涨幅 > 20%
- **入场时机**: 等待价格达到1.618-2.0扩展位区间（不是立即做空）
- **止损**: 入场价上方1%-2%
- **止盈**: 分批止盈（50%/100%/200%，30%/30%/40%仓位）
- **持仓时间**: 第二天上午到下午2点，最迟下午2点平仓
- **注意事项**: 
  - 检查做空费率，费率超过1%/4小时不做
  - 可结合裸K线、关键支撑阻力位确认

### 做多策略

- **筛选条件**: 24小时涨幅在 8%-12% 之间
- **入场**: 追涨入场
- **止损**: 从入场时的高点下跌7%时止损
- **止盈**: 涨幅达到20%开始分批止盈，20%-60%分批止盈
- **持仓时间**: 不限定日内，根据市场情况决定
- **风险提示**: 
  - 假突破率高（70-80%）
  - 需要严格止损
  - 胜率：10单赢1单（但1单盈利可覆盖所有亏损）

## 注意事项

1. **API限制**: 为避免API调用过快，脚本在处理做空币种的斐波那契扩展位时会有延迟（0.5秒/币种）
2. **数据质量**: 如果某个币种的K线数据获取失败，仍会生成基本交易计划
3. **大盘环境**: 如果大盘下杀5000点以上，建议暂停交易
4. **费率检查**: 做空前需要手动检查费率，费率超过1%/4小时不做
5. **信号质量**: 好信号不应该太多，如果太多就不是好信号

## 技术说明

### 数据来源

- **Bitget**: `https://api.bitget.com/api/spot/v1/market/tickers`
- **Bybit**: `https://api.bybit.com/v5/market/tickers`
- **Binance**: `https://api.binance.com/api/v3/ticker/24hr`

### 斐波那契扩展位计算

```
价格差 = high - low
1.618扩展位 = high + (价格差 × 0.618)
2.0扩展位 = high + (价格差 × 1.0)
入场区间：1.618扩展位到2.0扩展位（允许±2%容差）
```

## 常见问题

**Q: 为什么有些币种没有斐波那契扩展位数据？**

A: 如果无法获取日线K线数据，脚本仍会生成基本交易计划，但不会包含斐波那契扩展位信息。

**Q: 做空币种的入场区间是怎么计算的？**

A: 基于日线低点和高点计算斐波那契扩展位，入场区间为1.618-2.0扩展位之间，允许±2%容差。

**Q: 脚本会占用多少资源？**

A: 脚本运行时会调用交易所API，每次扫描大约需要1-2分钟（取决于符合条件的币种数量）。
