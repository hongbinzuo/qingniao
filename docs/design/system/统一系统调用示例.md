# 青鸟交易系统调用示例

## 快速调用

### 1. 运行所有系统（最简单）

```bash
python src/unified_trading_system.py
```

这将：
- 运行De.交易系统（分析BTC）
- 运行梦多空策略（扫描涨幅榜前100个币种）
- 生成2个交易计划文件

### 2. 只运行De.系统

```bash
python src/unified_trading_system.py --system de
```

### 3. 只运行梦多空策略

```bash
python src/unified_trading_system.py --system meng
```

## 详细调用示例

### 示例1：运行所有系统，自定义参数

```bash
python src/unified_trading_system.py --system all \
    --exchange bybit \
    --limit 50
```

说明：
- `--system all`: 运行所有系统
- `--exchange bybit`: 梦多空策略使用Bybit交易所
- `--limit 50`: 只扫描前50个币种

### 示例2：运行梦多空策略，扫描更多币种

```bash
python src/unified_trading_system.py --system meng \
    --exchange auto \
    --limit 200
```

说明：
- `--system meng`: 只运行梦多空策略
- `--exchange auto`: 自动选择最佳交易所
- `--limit 200`: 扫描前200个币种

### 示例3：在不同交易所运行

```bash
# 使用Bitget
python src/unified_trading_system.py --system meng --exchange bitget --limit 100

# 使用Binance
python src/unified_trading_system.py --system meng --exchange binance --limit 100

# 使用Bybit
python src/unified_trading_system.py --system meng --exchange bybit --limit 100

# 自动选择（推荐）
python src/unified_trading_system.py --system meng --exchange auto --limit 100
```

## Python代码中调用

### 方式1：使用统一管理器

```python
from src.unified_trading_system import UnifiedTradingSystem

# 创建系统实例
system = UnifiedTradingSystem()

# 运行所有系统
files = system.run_all_systems(
    exchange='auto',
    limit=100,
    de_symbol='BTC'
)

# 打印生成的文件
for f in files:
    print(f"生成文件: {f}")
```

### 方式2：单独调用De.系统

```python
from src.unified_trading_system import UnifiedTradingSystem

system = UnifiedTradingSystem()
de_file = system.run_de_system('BTC')
print(f"De.系统文件: {de_file}")
```

### 方式3：单独调用梦多空策略

```python
from src.unified_trading_system import UnifiedTradingSystem

system = UnifiedTradingSystem()
meng_file = system.run_meng_system(exchange='auto', limit=100)
print(f"梦多空策略文件: {meng_file}")
```

## 输出文件说明

### De.交易系统输出

**文件名格式**：`BTC_de_signals_YYYYMMDD_HHMMSS.md`

**内容包含**：
- BTC当前价格
- 5分钟/15分钟/1小时交易信号
- 技术分析（Vegas通道、VWAP、RSI、FVG等）
- 止损止盈建议
- 实时订单簿止损信息

### 梦多空策略输出

**文件名格式**：`梦多空策略_交易计划_YYYYMMDD_HHMMSS.md`

**内容包含**：
- 做空机会（24小时涨幅>20%）
  - 低点、高点
  - 1.618/2.0斐波扩展位
  - 入场区间、止损、止盈策略
- 做多机会（24小时涨幅8%-12%）
  - 入场价、止损价
  - 止盈策略

## 常见问题

### Q: 如何只运行其中一个系统？

A: 使用 `--system` 参数：
```bash
python src/unified_trading_system.py --system de   # 只运行De.系统
python src/unified_trading_system.py --system meng # 只运行梦多空策略
```

### Q: 如何查看帮助信息？

A: 使用 `--help` 参数：
```bash
python src/unified_trading_system.py --help
```

### Q: 生成的文件在哪里？

A: 所有文件都保存在项目根目录，例如：
- `C:\Users\zuoho\code\qimeng2\BTC_de_signals_20251228_161653.md`
- `C:\Users\zuoho\code\qimeng2\梦多空策略_交易计划_20251228_161713.md`

### Q: 如何批量运行多个交易所？

A: 使用循环：
```bash
# Windows PowerShell
foreach ($ex in @('bitget', 'bybit', 'binance')) {
    python src/unified_trading_system.py --system meng --exchange $ex --limit 100
}

# Linux/Mac bash
for ex in bitget bybit binance; do
    python src/unified_trading_system.py --system meng --exchange $ex --limit 100
done
```
