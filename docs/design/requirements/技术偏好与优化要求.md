## 执行效率优化

### Go语言替代原则
**规则**: 任何能用Go替代的可以用Go替代，以提高执行效率。

**适用范围**:
- 高频操作（如K线数据采集、实时价格监控）
- 性能敏感的计算（如技术指标计算、模式匹配）
- 并发处理任务（如多交易所数据同步）
- 系统服务/后台任务（如定时任务、API服务）

**保留Python的场景**:
- 数据分析和机器学习（scikit-learn, pandas, numpy生态）
- 快速原型开发和脚本
- 与现有Python代码库集成紧密的部分
- Gemini Vision API调用（已有Python实现，暂时保留）

**迁移优先级**:
1. **P0（高优先级）**: K线数据采集模块、实时价格同步
2. **P1（中优先级）**: 技术指标计算、模式匹配算法
3. **P2（低优先级）**: 辅助工具、批处理脚本

## 交易所选择优先级

### 交易数据获取优先级
**规则**: Gate.io 首选，Bitget 次之，币安（Binance）最后。

**优先级顺序**:
1. **Gate.io** (首选)
   - API稳定性好
   - 数据质量高
   - 响应速度快
2. **Bitget** (次选)
   - 作为Gate.io的备选
   - API兼容性好
3. **Binance** (最后)
   - 作为兜底方案
   - 仅在Gate和Bitget都不可用时使用

**实现要求**:
- 所有交易所数据获取函数应遵循此优先级
- 实现fallback机制：Gate → Bitget → Binance
- 记录使用的交易所，便于监控和调试

**现有代码位置**:
- `scripts/sherlock_scan_strong_coins.py`: 已实现优先级（Gate → Binance → Bitget），需要调整为 Gate → Bitget → Binance
- `scripts/falcon.py`: 已实现优先级，需要确认顺序
- `scripts/generate_style_filtered_signals.py`: 已实现优先级，需要确认顺序

### 交易所选择函数模板
```python
def get_market_data(symbol: str, exchange: str = None):
    """
    获取市场数据，按优先级：Gate → Bitget → Binance
    
    Args:
        symbol: 交易对符号
        exchange: 指定交易所（可选），如果为None则按优先级自动选择
    """
    providers = []
    if exchange == 'gate':
        providers = [_get_gate, _get_bitget, _get_binance]
    elif exchange == 'bitget':
        providers = [_get_bitget, _get_gate, _get_binance]
    else:
        # 默认优先级：Gate → Bitget → Binance
        providers = [_get_gate, _get_bitget, _get_binance]
    
    for provider in providers:
        try:
            data = provider(symbol)
            if data:
                return data
        except Exception:
            continue
    return None
```
