# 版本管理快速开始指南

## 🚀 5分钟快速开始

### 步骤1: 初始化Git仓库

**Windows**:
```bash
# 运行初始化脚本
init_git_repo.bat
```

**Linux/Mac**:
```bash
# 初始化Git
git init

# 创建develop分支
git checkout -b develop

# 添加文件
git add .

# 首次提交
git commit -m "feat: 初始化青鸟交易系统项目"
```

### 步骤2: 配置用户信息（首次使用）

```bash
git config user.name "Your Name"
git config user.email "your.email@example.com"
```

### 步骤3: 检查.gitignore

确保 `.gitignore` 文件已正确配置，特别是：
- ✅ 数据库文件已排除（`*.duckdb`, `*.db`）
- ✅ 输出文件已排除（`outputs/`, `*.md`交易信号）
- ✅ 敏感信息已排除（`*.env`, `secrets.json`）

### 步骤4: 首次提交

```bash
git add .
git commit -m "feat: 初始化青鸟交易系统项目"
```

## 📋 日常使用

### 开发新功能

```bash
# 1. 从develop创建功能分支
git checkout develop
git pull
git checkout -b feature/new-feature

# 2. 开发功能
# ... 编写代码 ...

# 3. 提交更改
git add .
git commit -m "feat: 添加新功能描述"

# 4. 推送到远程（如果有）
git push origin feature/new-feature
```

### 修复Bug

```bash
# 1. 从develop创建修复分支
git checkout develop
git checkout -b fix/bug-description

# 2. 修复Bug
# ... 修复代码 ...

# 3. 提交
git add .
git commit -m "fix: 修复Bug描述"

# 4. 合并到develop
git checkout develop
git merge fix/bug-description
```

## 🔍 常用命令

### 查看状态
```bash
git status          # 查看工作区状态
git log             # 查看提交历史
git log --oneline   # 简洁的提交历史
```

### 分支操作
```bash
git branch          # 查看所有分支
git branch -a       # 查看所有分支（包括远程）
git checkout branch # 切换分支
git merge branch    # 合并分支
```

### 提交操作
```bash
git add .           # 添加所有更改
git add file.py     # 添加特定文件
git commit -m "msg" # 提交更改
git push            # 推送到远程
git pull            # 从远程拉取
```

## ⚠️ 重要提醒

### 不要提交的文件

- ❌ 数据库文件（`*.duckdb`, `*.db`）
- ❌ 输出文件（`outputs/`, 交易信号文件）
- ❌ 敏感信息（`*.env`, `secrets.json`）
- ❌ 临时文件（`temp/`, `*.tmp`）
- ❌ 编译文件（`__pycache__/`, `target/`）

### 应该提交的文件

- ✅ 源代码（`src/*.py`）
- ✅ 配置文件模板（`*.example.json`）
- ✅ 设计文档（`docs/design/`）
- ✅ 数据库结构脚本
- ✅ README和说明文档
