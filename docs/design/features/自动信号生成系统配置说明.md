# 自动信号生成系统配置说明

## 当前配置

### 生成频率
- **间隔**: 每小时生成一次（1.0小时）
- **时间框架**: 5分钟和15分钟
- **币种数量**: Top 30（按市值排序）

### 币种选择
- **数据源**: 优先使用CoinGecko API按市值排序
- **回退方案**: 如果CoinGecko失败，使用Gate.io API按交易量排序
- **过滤规则**:
  - 排除稳定币（USDC, USDT, BUSD, TUSD, DAI, PAXG等）
  - 排除价格过低币种（< 0.0001）
  - 排除包装代币（包含下划线或连字符的币种）
  - 排除币种名称过长（> 10个字符）

### 信号生成
- **每个币种**: 生成5分钟和15分钟两个时间框架的信号
- **总信号数**: 30个币种 × 2个时间框架 = **60个信号/小时**
- **验证数据量**: 每小时60个信号，每天约1440个信号，数据量充足

### 信号格式
- 使用完整的ABU系统信号格式
- 包含Brooks概率评分
- 包含止损距离、建议仓位、风险金额等风险信息
- 完整的模式匹配信息（Pattern from page X）

## 启动方式

### 后台运行（推荐）
```bash
# Windows
scripts\start_auto_signal_generator.bat

# 查看状态
python scripts\show_auto_signal_status.py

# 停止
scripts\stop_auto_signal_generator.bat
```

### 单次运行（测试）
```bash
python scripts\auto_signal_generator.py --once --coins 30
```

### 自定义配置
```bash
# 每小时生成，Top 30币种
python scripts\auto_signal_generator.py --interval 1.0 --coins 30

# 每2小时生成，Top 50币种
python scripts\auto_signal_generator.py --interval 2.0 --coins 50

# 自定义时间框架
python scripts\auto_signal_generator.py --timeframes "5m,15m,1h"
```

## 输出文件

### 交易计划
- **位置**: `outputs/trading_plans/auto_generated_YYYYMMDD_HHMMSS.md`
- **格式**: Markdown格式，包含所有币种的5分钟和15分钟信号

### 状态文件
- **位置**: `outputs/auto_signal_status/current_status.json`
- **内容**: 当前运行状态、上次生成时间、下次生成时间等

### 历史记录
- **位置**: `outputs/auto_signal_status/generation_history.json`
- **内容**: 所有生成周期的历史记录

### 评估报告
- **位置**: `outputs/backtest_results/` 和 `outputs/feedback/`
- **内容**: 自动评估和回测结果

## 验证数据量

### 每小时
- 30个币种 × 2个时间框架 = **60个信号**

### 每天
- 60个信号 × 24小时 = **1,440个信号**

### 每周
- 1,440个信号 × 7天 = **10,080个信号**

### 每月
- 1,440个信号 × 30天 = **43,200个信号**

这个数据量足够进行：
- 模式识别验证
- 策略回测
- 信号质量评估
- 系统性能分析
- 机器学习训练（如需要）

## 注意事项

1. **API限制**: CoinGecko API有速率限制，如果频繁调用可能被限制
2. **网络稳定性**: 确保网络连接稳定，避免API调用失败
3. **存储空间**: 每小时生成一个报告文件，注意磁盘空间
4. **资源消耗**: 生成30个币种的信号需要一定时间（约1-2分钟）

## 监控建议

1. 定期检查状态文件，确保系统正常运行
2. 查看日志文件，及时发现错误
3. 监控生成的信号数量，确保达到预期
4. 检查评估结果，跟踪信号质量趋势
