# 模式库实时匹配方案

## 概述

将 PDF 教材中识别的图表模式库与实时价格图表（BTC、ETH等）进行匹配，实现：
1. **模式库管理**：从数据库中提取已识别的模式特征
2. **实时匹配**：在实时K线数据中寻找匹配的模式
3. **交易信号**：基于匹配结果生成交易建议

## 系统架构

```
PDF模式识别 → 模式库(数据库) → 特征提取 → 实时K线匹配 → 交易信号
     ↓              ↓                ↓              ↓           ↓
  llava分类    pattern_library   特征参数化    算法检测      入场/止损/止盈
```

### Python代码使用

```python

matcher = PatternLibraryMatcher()

# 1. 查看模式库
patterns = matcher.load_pattern_library('Triangle')
print(f"找到 {len(patterns)} 个三角形模式")

# 2. 实时匹配

    symbol='BTC_USDT',
    timeframe='5m',

    print(f"匹配到 {match['template_type']}: "
          f"入场={result['entry']}, "
          f"止损={result['stop_loss']}, "
          f"止盈={result['take_profit']}")
```

## 匹配算法

### 头肩顶/底匹配
1. 从模式库加载头肩顶模板
2. 提取特征：左右肩价格、头部价格、颈线位置
3. 在K线中寻找3个峰值/谷值
4. 验证形态特征：
   - 头部最高/最低
   - 左右肩相似（误差<3%）
   - 价格突破/跌破颈线
5. 计算交易点位：
   - 入场：颈线突破点
   - 止损：右肩外
   - 止盈：形态高度的0.618倍

### 三角形匹配
1. 识别三角形类型（上升/下降/对称）
2. 在K线中寻找边界线
3. 验证收敛趋势
4. 等待突破信号

### 内包线匹配
1. 检查最近K线是否形成内包
2. 根据方向判断交易信号

## 匹配策略

### 模板选择
- 每种类型选择**置信度最高的前3个**作为模板
- 优先匹配高质量模式

### 匹配优先级
1. **形态清晰度**: 形态越清晰，匹配权重越高
2. **时间周期匹配**: 优先匹配相同时间周期
3. **方向一致性**: 检查方向是否一致
4. **置信度阈值**: 只返回置信度>50%的匹配
