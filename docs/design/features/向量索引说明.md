# 向量索引说明 - ABU系统v3.0

## 一、什么是向量索引？

向量索引是一种数据结构，用于快速搜索高维向量空间中的相似向量。

### 1.1 为什么需要向量索引？

**当前问题**：
- 模式库有7229个模式
- 每次匹配需要遍历所有模式计算相似度
- 时间复杂度：O(n)，n=7229
- 如果模式库扩展到9000个，性能会进一步下降

**向量索引的优势**：
- 快速相似度搜索：O(log n) 或 O(1)
- 支持大规模数据：可以处理百万级向量
- 近似最近邻搜索：在精度和速度之间平衡

### 1.2 工作原理

```
传统方法（线性搜索）：
查询向量 → 遍历所有模式 → 计算相似度 → 排序 → 返回Top K
时间复杂度：O(n)

向量索引（近似最近邻）：
查询向量 → 索引快速定位候选 → 精确计算Top K → 返回结果
时间复杂度：O(log n) 或 O(1)
```

## 二、在ABU系统中的应用

### 2.1 使用场景

**场景1：模式相似度搜索**
- 输入：实时K线特征向量
- 输出：Top K相似模式
- 优势：从7229个模式中快速找到最相似的

**场景2：多源模式匹配**
- 输入：查询特征向量
- 输出：三个数据源中的相似模式
- 优势：并行搜索，快速融合

**场景3：模式去重和聚类**
- 输入：所有模式的特征向量
- 输出：相似模式分组
- 优势：识别重复模式，优化模式库

### 2.2 性能提升

**当前性能**（线性搜索）：
- 7229个模式：~0.05秒
- 9000个模式：~0.06秒（预估）

**使用向量索引后**（近似最近邻）：

## 三、技术选型

### 3.1 FAISS（Facebook AI Similarity Search）

**优势**：
- ✅ 性能优秀：支持GPU加速
- ✅ 功能丰富：多种索引类型
- ✅ 成熟稳定：Facebook开源，广泛使用
- ✅ 支持大规模：可处理十亿级向量

**适用场景**：
- 大规模模式库（>10,000个模式）
- 需要GPU加速
- 需要精确控制索引参数

**安装**：
```bash
pip install faiss-cpu  # CPU版本
pip install faiss-gpu  # GPU版本（需要CUDA）
```

### 3.2 Annoy（Approximate Nearest Neighbors Oh Yeah）

**优势**：
- ✅ 简单易用：API简洁
- ✅ 内存效率：索引文件小
- ✅ 跨平台：纯Python实现
- ✅ 持久化：索引可保存到磁盘

**适用场景**：
- 中小规模模式库（<100,000个模式）
- 需要简单易用的API
- 需要索引持久化

**安装**：
```bash
pip install annoy
```

### 3.3 推荐方案

**当前阶段（7229个模式）**：
- 推荐：**Annoy**
- 理由：简单易用，性能足够，索引文件小

**未来扩展（>10,000个模式）**：
- 推荐：**FAISS**
- 理由：性能更好，支持GPU加速

## 四、实现方案

### 4.1 特征向量化

**步骤1：提取特征**
```python
# 从模式中提取特征
features = {
    'kline_features': [...],
    'trend': 'bullish',
    'pattern_type': 'triangle',
    'direction': 'long'
}
```

**步骤2：向量化**
```python
# 转换为数值向量
vector = [
    kline_feature_1, kline_feature_2, ...,  # K线特征（one-hot编码）
    trend_bullish, trend_bearish, trend_neutral,  # 趋势（one-hot）
    pattern_triangle, pattern_wedge, ...,  # 模式类型（one-hot）
    direction_long, direction_short, direction_neutral  # 方向（one-hot）
]
```

**步骤3：归一化**
```python
# L2归一化
vector = vector / np.linalg.norm(vector)
```

### 4.2 建立索引

**步骤1：收集所有模式的特征向量**
```python
vectors = []
pattern_ids = []

for pattern in patterns:
    vector = vectorize_pattern(pattern)
    vectors.append(vector)
    pattern_ids.append(pattern.pattern_id)
```

**步骤2：建立索引**
```python
# 使用Annoy
from annoy import AnnoyIndex

dimension = len(vectors[0])
index = AnnoyIndex(dimension, 'angular')  # 使用余弦相似度

for i, vector in enumerate(vectors):
    index.add_item(i, vector)

index.build(10)  # 10棵树，越多越精确但越慢
index.save('pattern_index.ann')
```

**步骤3：保存映射**
```python
# 保存pattern_id到索引位置的映射
mapping = {i: pattern_ids[i] for i in range(len(pattern_ids)}
```

### 4.3 搜索

**步骤1：向量化查询**
```python
query_vector = vectorize_features(query_features)
```

**步骤2：搜索索引**
```python
# 加载索引
index = AnnoyIndex(dimension, 'angular')
index.load('pattern_index.ann')

# 搜索Top K
nearest_indices = index.get_nns_by_vector(query_vector, k=10)
```

**步骤3：映射回模式**
```python
results = [mapping[i] for i in nearest_indices]
```
