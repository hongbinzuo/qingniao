## 🎯 数据结构化方案

### 阶段1: 完善数据库数据（优先级：高）

#### 1.1 导入历史信号到数据库

**目标**: 将trading_signals/目录下的历史信号导入trading_signals表

**步骤**:
1. 解析Markdown文件，提取信号信息
2. 标准化信号格式
3. 导入到trading_signals表
4. 关联时间戳和价格数据

**预期结果**: 
- 导入约100-200个历史信号

3. 创建signal_evaluations记录
4. 更新trading_signals状态

**预期结果**:
- 创建约100-200条评估记录
- 为ML训练提供标签数据

#### 1.3 补充交易记录

**预期结果**:
- 补充约50-100条交易记录

### 阶段2: 特征工程（优先级：高）

#### 2.1 价格特征

**从时序数据提取**:
- 技术指标: EMA, VWAP, RSI, MACD, Bollinger Bands
- 价格变化: 收益率、波动率、成交量变化
- 市场结构: 趋势、震荡、突破、回调

**实现**:
```python
def extract_price_features(klines, current_price):
    features = {
        'ema_144': calculate_ema(klines, 144),
        'ema_169': calculate_ema(klines, 169),
        'vwap': calculate_vwap(klines),
        'rsi': calculate_rsi(klines),
        'volatility': calculate_volatility(klines),
        'trend_strength': calculate_trend_strength(klines),
        'market_state': classify_market_state(klines)
    }
    return features
```

#### 2.2 对话特征

**从对话和观点提取**:
- 情绪特征: 看涨/看跌/中性
- 策略特征: 使用的策略类型
- 时间特征: 交易时间偏好
- 价格关联: 观点提及的价格水平

**实现**:
```python
def extract_conversation_features(viewpoints, conversations):

        'time_preference': analyze_time_pattern(viewpoints),

    }
    return features
```

## 🚀 综合训练方案

### 方案1: 信号成功率预测（监督学习）

**数据**:
- 特征: 价格特征 + 对话特征 + 规则特征
- 标签: 信号评估结果（成功/失败）

**模型**:
- 随机森林分类器（已有）
- XGBoost分类器（增强）
- 神经网络分类器（深度学习）

**训练流程**:
```python
1. 加载历史信号和评估数据
2. 提取特征（价格、对话、规则）
3. 准备标签（成功/失败）
4. 划分训练集/验证集/测试集
5. 训练模型
6. 评估性能
7. 保存模型
```

### 方案2: 价格预测（时间序列）

**数据**:
- 输入: 历史价格序列（多时间框架）
- 输出: 未来价格预测

**模型**:
- LSTM（已有基础）
- Transformer（增强）
- Prophet（传统）

**训练流程**:
```python
1. 加载时序数据（5m, 15m, 1h）
2. 计算技术指标
3. 创建时间序列窗口
4. 训练LSTM/Transformer模型
5. 评估预测准确率
6. 保存模型
```

### 方案3: 交易策略学习（强化学习）

**数据**:
- 环境: 历史价格数据
- 状态: 市场环境特征
- 动作: 买入/卖出/持有
- 奖励: 收益率（考虑风险）

**模型**:
- PPO（TensorTrade）
- DQN
- A3C

**训练流程**:
```python
1. 创建交易环境（使用历史数据）
2. 初始化RL智能体
3. 训练智能体（与环境交互）
4. 评估策略性能
5. 保存模型
```

### 方案4: 交易员行为建模（无监督学习）

**数据**:
- 对话和观点序列
- 交易记录序列

**模型**:
- 序列模型（LSTM/GRU）
- 聚类分析
- 关联规则挖掘

**训练流程**:
```python
1. 提取交易员行为序列
2. 训练序列模型
3. 识别行为模式
4. 生成行为规则
```
