## 🔍 算法说明

### 形态检测逻辑

1. **看涨形态**: 从 `BullishPatternsWithSignals` 模块获取
2. **反转形态**: 从 `ChartPatternsDetector` 模块获取
3. **看跌形态**: 基于现有逻辑扩展（镜像看涨形态的逻辑）

### 信号格式统一

所有信号都遵循统一格式：
- `name`: 形态名称
- `type`: 'long' 或 'short'
- `entry`: 入场价格（买入点或卖出点）
- `stop_loss`: 止损价格
- `entry_model`: 入场模型标识
- `reason`: 入场原因说明
- `strength`: 强度评分（0-100）
