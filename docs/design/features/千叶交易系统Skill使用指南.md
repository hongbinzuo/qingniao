# 千叶交易系统 - Skill使用指南

**创建时间**: 2025-12-30  
**系统**: 千叶交易系统

---

## 🎯 概述

在Claude Code环境中，可以直接使用skill能力来分析视频和图片，无需手动安装复杂的依赖。

---

## 📹 视频分析

### 方式1: 直接上传视频

**步骤**:
1. 在Claude Code中上传视频文件
2. 或提供YouTube视频链接
3. Claude会自动分析视频内容

**示例**:
```
请分析这个视频中的交易规则：
[上传视频文件或提供链接]
```

### 方式2: 使用Skill

**步骤**:
1. 在对话中提及相关的skill
2. 提供视频链接或文件
3. Skill会自动处理

**示例**:
```
使用 @video_analyzer_skill 分析这个视频：
https://www.youtube.com/watch?v=xxxxx
```

### 方式3: 直接描述需求

**示例**:
```
请总结这个视频中的交易规则：
- 入场条件是什么？
- 止损策略是什么？
- 止盈策略是什么？
- 风险管理方法是什么？

[上传视频或提供链接]
```

## 🔧 集成到系统

### 1. 在Claude Code中分析

直接在Claude Code对话中：
- 上传视频/图片
- 描述分析需求
- 获取分析结果

### 2. 保存分析结果

分析完成后，将结果保存到系统：

```python
# 保存到文件
analysis_result = {
    'video_url': '...',
    'transcript': '...',
    'trading_rules': [...],
    'summary': '...'
}

# 保存到 data/chiba_skills/
```

### 3. 提取交易规则

从分析结果中提取结构化规则：

```python
from chiba_trading_system.skill_integration import SkillIntegration

integrator = SkillIntegration()
rules = integrator.extract_trading_rules_from_skill_result(analysis_result)
```

### 4. 编码规则

将提取的规则编码到系统：

```python
# 创建规则配置文件
# data/chiba_skills/chiba_rules.yaml
```

## 📋 工作流程

### 完整流程

```
1. 在Claude Code中上传视频/图片
   ↓
2. Claude自动分析（使用skill能力）
   ↓
3. 获取分析结果（转录、规则、标注等）
   ↓
4. 提取结构化交易规则
   ↓
5. 编码到规则引擎
   ↓
6. 集成到交易系统
   ↓
7. 生成交易信号
```

### 简化流程（推荐）

```
1. 在Claude Code对话中：
   - 上传视频/图片
   - 描述："请分析这个视频/图片中的交易规则"
   ↓
2. Claude自动分析并总结
   ↓
3. 确认规则后，编码到系统
```

## 🎯 最佳实践

### 视频分析

1. **提供清晰的视频链接或文件**
2. **明确分析需求**:
   - "请总结交易规则"
   - "请提取入场条件"
   - "请提取止损策略"

3. **分步骤分析**:
   - 先总结整体内容
   - 再提取具体规则
   - 最后验证规则完整性

### 图片分析

1. **提供清晰的图片**
2. **指定提取内容**:
   - 入场点
   - 止损点
   - 止盈点
   - 技术指标
   - 图表形态

3. **多图片分析**:
   - 可以上传多张图片
   - 对比分析
   - 提取共同规则

## 💡 优势

### 使用Skill的优势

1. **无需安装复杂依赖**
   - 不需要yt-dlp
   - 不需要Whisper
   - 不需要OCR工具

2. **自动处理**
   - Claude自动识别内容
   - 自动提取关键信息
   - 自动总结规则

3. **交互式分析**
   - 可以随时提问
   - 可以深入分析
   - 可以验证规则

4. **高质量结果**
   - Claude理解能力强
   - 提取准确
   - 总结完整
