# 模式库文字说明提取与匹配方案

## 问题发现

用户指出：PDF页面中**不仅有图形，还有重要的交易策略文字说明**，例如：
- "20-Gap bar buy in small PB bull trend so 75% chance of test of high of day"

这些文字说明包含：
- **模式名称**（如 "Gap bar"）
- **交易方向**（如 "buy"）
- **市场环境**（如 "small PB bull trend"）
- **概率/成功率**（如 "75% chance"）
- **目标**（如 "test of high of day"）

## 当前状态

### 已识别的问题
1. **PDF原始文本**：只有页脚文字，无实际内容
   - 说明PDF是扫描版，文字在图片中
   
2. **数据库中的文字**：
   - `context_text` 字段：只有页脚文字
   - `chart_features_json.ocr_text`：大部分为空
   - `gemini_annotation_json`：未使用或为空

3. **缺少的关键信息**：
   - 图表上的文字说明
   - 交易策略描述
   - 成功概率
   - 入场条件

### 步骤2: 解析文字说明为结构化数据

提取关键信息：

```python
import re

def parse_trading_description(text):
    """解析交易策略文字说明"""
    result = {
        'pattern_name': None,
        'direction': None,
        'market_condition': None,
        'probability': None,
        'target': None,
        'entry_condition': None
    }
    
    # 提取模式名称（如 "Gap bar"）
    pattern_match = re.search(r'(\d+[-.])?\s*([A-Z][a-z]+(?:\s+[A-Z][a-z]+)*)', text)
    if pattern_match:
        result['pattern_name'] = pattern_match.group(2)
    
    # 提取方向（buy/sell/long/short）
    if re.search(r'\b(buy|long)\b', text, re.I):
        result['direction'] = 'long'
    elif re.search(r'\b(sell|short)\b', text, re.I):
        result['direction'] = 'short'
    
    # 提取概率
    prob_match = re.search(r'(\d+)%\s*chance', text, re.I)
    if prob_match:
        result['probability'] = int(prob_match.group(1))
    
    # 提取目标
    if 'test of high' in text.lower():
        result['target'] = 'test_of_high_of_day'
    elif 'test of low' in text.lower():
        result['target'] = 'test_of_low_of_day'
    
    # 提取市场环境（如 "bull trend", "small PB"）
    if 'bull' in text.lower():
        result['market_condition'] = 'bullish'
    elif 'bear' in text.lower():
        result['market_condition'] = 'bearish'
    
    return result
```

### 步骤3: 更新模式库匹配器

在匹配时使用文字说明：

```python
class PatternLibraryMatcher:
    def match_with_text_description(self, pattern, klines):
        """使用文字说明辅助匹配"""
        
        # 1. 从OCR文字提取交易信号
        ocr_text = pattern.get('ocr_text', '')
        text_signal = parse_trading_description(ocr_text)
        
        # 2. 基于文字说明匹配
        if text_signal['pattern_name'] == 'Gap bar':
            # 检测Gap bar模式
            gap_result = detect_gap_bar(klines)
            
            # 验证文字说明中的条件
            if text_signal['market_condition'] == 'bullish':
                if not is_bull_trend(klines):
                    return None  # 不符合条件
            
            if text_signal['probability']:
                # 使用概率调整置信度
                gap_result['confidence'] *= (text_signal['probability'] / 100)
            
            if text_signal['target'] == 'test_of_high_of_day':
                # 设置目标为日内高点
                gap_result['take_profit'] = get_high_of_day(klines)
            
            return gap_result
        
        return None
```

## 匹配策略升级

### 增强匹配逻辑

1. **文字说明 + 图形识别**：
   - 先用OCR提取文字说明
   - 再用图形识别算法验证
   - 两者结合提高准确性

2. **文字关键词匹配**：
   - 提取文字中的模式名称、方向、条件
   - 在实时图表中搜索匹配这些条件
   - 例如："Gap bar" + "bull trend" + "buy" → 搜索看涨Gap bar

3. **概率信息利用**：
   - 文字中的概率（如"75% chance"）可以作为置信度权重
   - 不同概率的模式有不同的匹配优先级
