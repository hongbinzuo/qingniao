# 信号结果反馈系统说明

## 功能概述

信号结果反馈系统用于追踪生成的交易信号的实际表现，定期检查信号状态，记录信号是否被激活、是否止损或止盈。

## 核心功能

### 1. 信号状态追踪

系统追踪每个信号的状态变化：

- **pending（待激活）**: 信号已生成，价格尚未接近入场价（距离入场价>1%）
- **active（交易中）**: 价格已接近入场价（距离入场价<1%），已标记为入场
- **quick_tp（快速止盈）**: 达到0.5%的快速止盈，已设置保本止损
- **partial_tp（部分止盈）**: 已触及第一止盈位，已设置保本止损
- **full_tp（全部止盈）**: 已触及第二止盈位（全部止盈）
- **stopped（已止损）**: 价格触及止损位（可能是初始止损或保本止损）
- **expired（已过期）**: 信号超过有效期未激活

### 2. 检查时间间隔

- **5分钟信号**: 每10分钟检查一次
- **15分钟信号**: 每30分钟检查一次

### 3. 信号有效期

- **5分钟信号**: 2小时后未激活则标记为过期
- **15分钟信号**: 4小时后未激活则标记为过期

### 4. 快速止盈和保本止损逻辑

#### 快速止盈（0.5%）

- 当信号激活后，如果盈亏达到0.5%：
  - 标记为 `quick_tp`（快速止盈）
  - 自动设置保本止损（止损移动到入场价）
  - 记录为获利单

#### 保本止损

- 触发条件：
  1. 达到0.5%快速止盈时
  2. 达到第一止盈位（TP1）时
  
- 效果：
  - 止损位移动到入场价
  - 如果之后触及保本止损，状态为"部分止盈"而不是"止损"
  - 确保至少保本或小幅盈利

### 5. 止盈判定方式

系统支持两种止盈判定方式：

1. **原计划止盈**：
   - 按照信号生成时的止盈1和止盈2
   - 达到TP1 → 部分止盈，设置保本止损
   - 达到TP2 → 全部止盈

2. **快速止盈（0.5%）**：
   - 做多：价格上涨0.5%
   - 做空：价格下跌0.5%
   - 达到后立即标记为快速止盈，设置保本止损

## 实现细节

### 文件结构

- **核心模块**: `src/abu/signal_result_feedback.py`
- **数据存储**: `outputs/auto_signal_status/signal_feedback/`
  - `active_signals.json`: 活跃信号列表
  - `feedback_history.json`: 反馈历史记录

### 主要方法

#### `add_signal(signal, generated_time)`
添加新信号到追踪列表

#### `check_signal_status(signal)`
检查单个信号状态，返回新状态和更新信息

#### `check_all_signals()`
检查所有活跃信号，返回统计信息

#### `get_feedback_report()`
生成反馈报告

### 整合到自动信号生成系统

在 `scripts/auto_signal_generator.py` 中：

1. **初始化**: 在 `__init__` 中创建 `SignalResultFeedback` 实例
2. **添加信号**: 在生成信号后，调用 `add_signal()` 添加到追踪列表
3. **检查状态**: 在每次运行周期开始时，调用 `check_all_signals()` 检查所有活跃信号
4. **生成报告**: 在总结报告中包含反馈统计信息

## 使用示例

### 自动运行

系统会在每次运行周期时自动：
1. 检查所有活跃信号的状态
2. 更新信号状态（激活、止损、止盈等）
3. 生成反馈报告
4. 在总结报告中显示反馈统计

### 手动检查

```python
from src.abu.signal_result_feedback import SignalResultFeedback

feedback = SignalResultFeedback()
stats = feedback.check_all_signals()
print(f"检查结果: {stats}")

report = feedback.get_feedback_report()
print('\n'.join(report))
```

## 反馈报告内容

反馈报告包含：

1. **状态统计**:
   - 总信号数
   - 各状态的数量（待激活、交易中、快速止盈、部分止盈、全部止盈、已止损、已过期）

2. **详细列表**:
   - 每个信号的详细信息
   - 币种、时间框架、方向
   - 入场价、退出价
   - 盈亏百分比
   - 退出原因

## 数据存储

### active_signals.json

存储所有活跃信号的完整信息，包括：
- 信号ID、币种、时间框架
- 交易参数（入场价、止损、止盈）
- 状态信息（当前状态、入场时间、退出时间等）
- 盈亏信息

### feedback_history.json

存储状态变更历史，包括：
- 信号ID
- 状态变更时间
- 旧状态和新状态
- 退出价格和原因
- 盈亏百分比

## 注意事项

1. **价格获取**: 使用 Gate.io API 获取实时价格，如果API失败会跳过检查
2. **信号过期**: 超过有效期的信号会被标记为过期，不再检查
3. **保本止损**: 一旦设置保本止损，后续如果触及止损，状态为"部分止盈"而不是"止损"
4. **快速止盈**: 0.5%的快速止盈优先级高于原计划止盈，先达到先触发
