# 系统唤醒后自动恢复运行说明

## 问题
当电脑休眠或重启后，后台运行的自动信号生成器会停止，需要手动重新启动。

## 解决方案

### 方案1: 使用监控脚本（推荐）

#### 步骤1: 创建监控脚本
已创建 `scripts/monitor_auto_signal_generator.bat`，该脚本会：
- 检查进程是否运行
- 如果未运行，自动启动程序

#### 步骤2: 设置Windows任务计划程序

**方法A: 使用PowerShell脚本（推荐）**
```powershell
# 以管理员身份运行PowerShell
cd C:\Users\zuoho\code\qingniao
.\scripts\setup_auto_start_on_wake.ps1
```

**方法B: 使用批处理脚本**
```cmd
# 以管理员身份运行命令提示符
cd C:\Users\zuoho\code\qingniao
scripts\setup_auto_start_on_wake.bat
```

**方法C: 手动设置任务计划程序**
1. 打开"任务计划程序"（`taskschd.msc`）
2. 创建基本任务
3. 触发器设置：
   - 系统启动时
   - 用户登录时
   - 每5分钟运行一次（监控进程）
4. 操作：启动程序
   - 程序：`cmd.exe`
   - 参数：`/c "C:\Users\zuoho\code\qingniao\scripts\monitor_auto_signal_generator.bat"`
5. 条件：
   - ✅ 只有在以下网络连接可用时才启动
   - ✅ 唤醒计算机运行此任务
6. 设置：
   - ✅ 允许按需运行任务
   - ✅ 如果请求时任务正在运行，则并行启动新实例

### 方案2: 手动重启（临时方案）

如果系统已唤醒但程序未运行：

```cmd
# 方法1: 使用启动脚本
scripts\start_auto_signal_generator.bat

# 方法2: 直接运行
python scripts\auto_signal_generator.py --interval 1.0 --coins 30
```

### 方案3: 使用系统服务（高级）

如果需要更稳定的后台运行，可以考虑将程序注册为Windows服务，但这需要额外的配置。

## 监控脚本说明

### monitor_auto_signal_generator.bat
- **功能**: 检查进程是否运行，如果未运行则自动启动
- **运行频率**: 建议每5分钟运行一次
- **日志**: 输出到控制台（可在任务计划程序中配置日志文件）

### 工作原理
1. 检查PID文件是否存在
2. 如果不存在，直接启动程序
3. 如果存在，检查进程是否还在运行
4. 如果进程未运行，删除PID文件并重新启动

## 故障排除

### 问题1: 任务创建失败
- **原因**: 没有管理员权限
- **解决**: 右键点击脚本，选择"以管理员身份运行"

### 问题2: 任务运行但程序未启动
- **检查**: 查看任务计划程序中的"上次运行结果"
- **检查**: 查看脚本输出日志
- **解决**: 确保Python路径正确，脚本路径正确

### 问题3: 程序启动但立即退出
- **检查**: 查看错误日志 `outputs\logs\auto_signal_generator_error.log`
- **检查**: 数据库文件是否被锁定
- **解决**: 确保没有其他实例在运行

## 最佳实践

1. **使用任务计划程序**: 最可靠的方法
2. **设置监控频率**: 每5分钟检查一次，平衡及时性和系统资源
3. **启用网络检查**: 确保只有在网络可用时才启动
4. **查看日志**: 定期检查日志文件，确保程序正常运行
