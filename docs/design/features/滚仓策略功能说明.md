# 浮云滚仓策略功能说明

## ✅ 已完成的功能

### 1. 滚仓策略管理器模块 ✅

**文件**: `src/rolling_position_manager.py`

**核心功能**:
- ✅ **滚仓策略分析**: 分析交易信号是否适合滚仓
- ✅ **滚仓建议生成**: 为符合条件的信号生成具体滚仓操作建议
- ✅ **风险控制**: 使用浮盈加仓，不增加额外风险

### 2. 滚仓策略规则 ✅

#### 基本参数
- **初始风险**: 1%（可配置）
- **金字塔层级**: 0.5R, 1.0R, 1.5R, 2.0R（可配置）
- **加仓比例**: 每次加仓30%（可配置）
- **最大仓位**: 3倍初始仓位（可配置）

#### 滚仓条件
1. **风险回报比**: 至少2:1
2. **信号强度**: 至少中等强度
3. **明确止盈位**: 必须有明确的止盈价位
4. **浮盈要求**: 至少0.5R的浮盈才考虑滚仓

### 3. 滚仓操作类型 ✅

1. **移动止损**
   - 当达到0.5R盈利时，将止损移至入场价（盈亏平衡点）
   - 锁定利润，无额外风险

2. **加仓操作**
   - 在1.0R、1.5R、2.0R盈利时，使用浮盈加仓30%
   - 使用浮盈进行加仓，不增加额外风险
   - 逐步建立金字塔式仓位

3. **分批止盈**
   - 第一止盈位：止盈30%仓位
   - 第二止盈位：止盈30%仓位
   - 保留40%仓位继续持有，追求更大利润

### 4. 集成到De.交易系统 ✅

**集成方式**:
- ✅ 在5分钟和15分钟信号生成后自动分析
- ✅ 为符合条件的信号生成滚仓建议
- ✅ 在报告中单独章节显示
- ✅ 提供详细的操作建议和风险说明

### 5. 报告显示 ✅

在交易信号报告中：
- ✅ 在信号详情后显示"滚仓策略建议"章节
- ✅ 显示当前浮盈（以R为单位）
- ✅ 显示当前所处的金字塔层级
- ✅ 列出具体的滚仓操作建议
- ✅ 说明每个操作的风险情况

## 📊 使用场景

### 主要用途

1. **盈利最大化**
   - 在盈利时逐步加仓，放大收益
   - 使用浮盈加仓，不增加初始风险
   - 分批止盈，保留部分仓位追求更大利润

2. **风险控制**
   - 使用浮盈加仓，不增加额外风险
   - 移动止损至盈亏平衡点，锁定利润
   - 分批止盈，逐步锁定利润

3. **仓位管理**
   - 金字塔式加仓，逐步建立仓位
   - 最大仓位限制，避免过度加仓
   - 灵活调整仓位大小

## 🔧 技术实现

### 核心算法

1. **浮盈计算**
   - 当前浮盈 = (当前价格 - 入场价) / 初始风险
   - 以R为单位，便于统一衡量

2. **层级判断**
   - 根据当前浮盈判断所处的金字塔层级
   - 确定下一层级的目标价格

3. **加仓计算**
   - 加仓价格 = 入场价 + (目标R × 初始风险)
   - 加仓比例 = 30%（可配置）

### 风险控制

- ✅ 只使用浮盈加仓，不增加额外风险
- ✅ 移动止损至盈亏平衡点，锁定利润
- ✅ 分批止盈，逐步锁定利润
- ✅ 最大仓位限制，避免过度加仓

## 🔍 算法说明

### 滚仓判断逻辑

1. **信号筛选**
   - 风险回报比 ≥ 2:1
   - 信号强度 ≥ 中等
   - 有明确的止盈位

2. **浮盈评估**
   - 计算当前浮盈（以R为单位）
   - 判断是否达到最小浮盈要求（0.5R）

3. **层级判断**
   - 根据浮盈确定当前层级
   - 确定下一层级的目标价格

4. **建议生成**
   - 移动止损建议
   - 加仓操作建议
   - 分批止盈建议
