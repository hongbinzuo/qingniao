   - 两根大阳线夹一小阴线
   - 强度评分: 85%

4. ✅ **揭竿而起** (Rising from the Ground)
   - 突然大幅上涨强势反转
   - 强度评分: 80%

5. ✅ **小步上扬** (Small Steps Upward)
   - 连续小阳线稳步上涨
   - 强度评分: 70%

6. ✅ **均线多头布林突破** (Moving Average Bullish Bollinger Breakout)
   - 突破阻力位强势上涨
   - 强度评分: 75%

7. ✅ **单阳盖阴** (Single Bullish Candle Covering Bearish)
   - 大阳线完全吞没前一根阴线
   - 强度评分: 85%

8. ✅ **立竿见影** (Instant Effect)
   - 下跌后突然大幅上涨快速反转
   - 强度评分: 80%

9. ✅ **上升三法** (Rising Three Methods)
   - 上涨后整理然后继续上涨
   - 强度评分: 80%

## 🎯 使用场景

### 主要用途

1. **做多信号确认**
   - 识别看涨K线形态，确认做多机会
   - 结合其他技术分析，提高做多信号的可靠性
   - 建议：当起飞强度>50%时，考虑做多

2. **入场时机选择**
   - 识别K线形态确认的入场时机
   - 在形态确认后入场
   - 根据形态强度调整入场时机

3. **趋势启动识别**
   - 识别趋势启动的K线信号
   - 判断价格是否即将起飞
   - 在起飞前或起飞初期入场

## 📈 与其他模块的配合

### 完整的交易信号流程

1. **图表形态识别** → 识别具体的形态（如双底、头肩底等）
2. **下降趋势识别** → 识别下降趋势特征（判断是否适合做多）
3. **主力洗盘场景识别** → 识别洗盘后的做多机会
4. **K线起飞形态识别** → 识别K线形态确认的做多信号 ✅
5. **原有技术分析** → FVG、Vegas、VWAP等信号
6. **ML预测评分** → 评估信号成功率

### 综合判断

- 当多个模块同时识别到做多机会时，信号强度更高
- 例如：图表形态识别到双底 + 主力洗盘场景识别到箱体震荡 + K线起飞形态识别到红三兵 = 强做多信号
