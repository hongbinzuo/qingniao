# 更新说明 - 入场模型标注功能

## 更新内容

### 1. 修正术语
- ✅ 将"拼爸"更正为"Pinbar"（K线反转形态）

### 2. 增强信号标注
每次生成的交易信号现在都包含：
- **入场模型**：明确标注是什么模型触发的信号
- **入场原因**：详细说明为什么在这个位置入场

### 3. 支持的入场模型

系统现在可以识别和标注以下入场模型：

1. **VWAP入场**
   - 标注：【VWAP】或【VWAP + Pinbar确认】
   - 说明：价格在VWAP附近的反转

2. **Vegas通道入场**
   - 标注：【Vegas通道】或【Vegas通道突破】或【Vegas通道 + Pinbar确认】
   - 说明：EMA144/169通道的支撑阻力转换

3. **Pinbar入场**
   - 标注：【Pinbar】
   - 说明：影线长、实体小的反转信号
   - 识别规则：
     - 看涨Pinbar：下影线>60%，实体<30%，上影线<10%
     - 看跌Pinbar：上影线>60%，实体<30%，下影线<10%

4. **FVG回填**（ICT相关）
   - 标注：【FVG回填】或【FVG回填 + Pinbar确认】
   - 说明：Fair Value Gap回填，价格缺口通常会被回填

5. **支撑/阻力位**（区间突破相关）
   - 标注：【支撑位反弹】或【阻力位回落】
   - 说明：价格在关键支撑/阻力位附近的反转

### 4. 信号输出格式

现在每个信号都包含：

```
**做空** (强)
入场: $88,456
止损: $90,208
止盈: $86,703 (50%) / $85,827 (50%)
**入场模型**: FVG回填
**入场原因**: 【FVG回填】下跌FVG做空机会，FVG区间(87579-87580)，价格可能回填到87579
```
