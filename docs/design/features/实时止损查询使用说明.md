# 实时订单簿止损查询工具使用说明

## 功能说明

这是一个实时订单簿止损查询工具，当你执行交易计划需要设置止损时，可以立即获取实时订单簿数据并给出基于流动性的止损建议。

## 使用方法

### 基本用法

```bash
python get_realtime_stop_loss.py <币种> <方向> sl [入场价]
```

### 参数说明

- **币种**: BTC, ETH, BNB 等（支持主流币种）
- **方向**: 
  - `long` - 做多
  - `short` - 做空
- **sl**: 止损查询标识（固定参数）
- **入场价**: 可选，如果不提供则使用当前价格

## 使用示例

### 示例1：BTC做多，使用当前价格作为入场价

```bash
python get_realtime_stop_loss.py BTC long sl
```

### 示例2：BTC做多，指定入场价86000

```bash
python get_realtime_stop_loss.py BTC long sl 86000
```

### 示例3：BTC做空，指定入场价90000

```bash
python get_realtime_stop_loss.py BTC short sl 90000
```

### 示例4：ETH做多，指定入场价2500

```bash
python get_realtime_stop_loss.py ETH long sl 2500
```

## 输出说明

工具会返回以下信息：

1. **币种和方向**: 确认交易对和方向
2. **入场价**: 你提供的入场价或当前价格
3. **当前价格**: 实时市场价格
4. **数据来源**: 获取订单簿的交易所（Binance/Bybit/OKX/Gate.io）
5. **建议止损价**: 基于实时订单簿计算的止损价格
6. **止损距离**: 止损距离（点数和百分比）
7. **止损理由**: 止损设置的依据
8. **支撑/阻力位**: 订单簿中的关键价格位

## 工作原理

1. **多交易所支持**: 自动尝试从多个交易所获取订单簿（Binance → Bybit → OKX → Gate.io）
2. **实时流动性分析**: 分析订单簿中的买单/卖单分布
3. **智能止损计算**:
   - **做多**: 止损放在买单密集区下方，流动性稀疏区
   - **做空**: 止损放在卖单密集区上方，流动性稀疏区
4. **距离控制**: 止损距离控制在0.3%-2%之间，确保合理

## 快速指令参考

### 常用指令

```bash
# BTC做多止损（当前价）
python get_realtime_stop_loss.py BTC long sl

# BTC做多止损（指定价）
python get_realtime_stop_loss.py BTC long sl 86000

# BTC做空止损（指定价）
python get_realtime_stop_loss.py BTC short sl 90000
```

## 注意事项

1. **实时性**: 订单簿数据是实时的，每次查询都会获取最新数据
2. **网络要求**: 需要能够访问交易所API（Binance等）
3. **价格单位**: 价格单位为USDT
4. **止损建议**: 仅供参考，实际交易时建议结合实时订单簿观察

## 故障排除

如果无法获取订单簿数据：

1. 检查网络连接
2. 确认交易所API是否可访问
3. 工具会自动尝试多个交易所，通常至少有一个能成功

## 集成到交易流程

建议在以下场景使用：

1. **执行交易计划时**: 当De.给出交易指令，需要设置止损时
2. **调整止损时**: 当价格变化需要调整止损位置时
3. **加仓时**: 当需要为新头寸设置止损时

## 快捷方式（可选）

可以创建批处理文件或别名来简化命令：

**Windows (stop_loss.bat)**:
```batch
@echo off
python get_realtime_stop_loss.py %*
```

**Linux/Mac (stop_loss.sh)**:
```bash
#!/bin/bash
python get_realtime_stop_loss.py "$@"
```

然后就可以直接使用：
```bash
stop_loss BTC long sl 86000
```
