## 📊 关键概念

### 1. 起涨点 (88535)

**定义**：
- 5分钟图上的起涨点
- 价格从这一点开始上涨的起点
- 作为关键支撑位

**重要性**：
- 这是多空分界线
- 如果跌破起涨点，趋势可能反转
- 作为判断真假突破的参考点

**交易意义**：
- 做多时，止损放在起涨点附近
- 做空时，目标是起涨点附近或上方

### 2. 次高（未突破89354）

**定义**：
- 如果价格从起涨点上涨，但没有突破阻力位（89354），就形成了次高
- 次高 = 高点低于阻力位，形成次高点后回调

**特征**：
- 高点低于阻力位（89354）
- 形成次高点后回调
- 如果跌破起涨点，就是反转信号

**交易信号**：
- **条件**: 次高形成 + 跌破起涨点
- **操作**: 用力空（做空）
- **逻辑**: 上涨失败，趋势可能反转

### 3. 突破的两种可能

#### 3.1 真突破（收线突破89354）

**特征**：
- 价格突破阻力位（89354）
- **K线收盘价在阻力位之上**（这是关键！）
- 有效突破，趋势继续向上

**交易策略**：
- **操作**: 继续做多
- **止损**: 放在起涨点附近
- **逻辑**: 真突破表示趋势继续，应该跟随趋势

#### 3.2 假突破（扫了就夸了）

**特征**：
- 价格短暂突破阻力位（89354）
- 但很快回落（"扫了" = 被扫止损，诱多）
- **收盘价没有站稳在阻力位之上**
- 假突破，可能反转

**交易策略**：
- **操作**: 做空
- **目标**: 吃到起涨点上面一点
- **逻辑**: 假突破通常是诱多，后续可能大幅回调

## 📈 详细交易策略

### 场景1: 形成次高 + 跌破起涨点

**条件**：
1. 价格从起涨点（88535）起涨
2. 上涨但没有突破阻力位（89354）
3. 形成次高点（低于89354）
4. 价格跌破起涨点（88535）

**操作**：
- **动作**: 用力空（做空）
- **逻辑**: 次高形成后跌破起涨点，说明上涨失败，趋势可能反转
- **目标**: 可以看更低的位置

**示例**：
```
起涨点: 88535
阻力位: 89354
次高点: 89200（未突破89354）
价格跌破: 88535
操作: 用力空
```

### 场景2: 假突破（扫了）

**条件**：
1. 价格短暂突破阻力位（89354）
2. 但很快回落（扫止损，诱多）
3. 收盘价没有站稳在阻力位之上
4. K线形成上影线或收在阻力位下方

**操作**：
- **动作**: 做空
- **目标**: 吃到起涨点上面一点（约88635）
- **逻辑**: 假突破通常是诱多，后续可能大幅回调

**示例**：
```
阻力位: 89354
价格突破: 89400
但收盘价: 89200（假突破）
操作: 做空
目标: 88635（起涨点上面一点）
```

### 场景3: 真突破（收线突破）

**条件**：
1. 价格突破阻力位（89354）
2. **K线收盘价在阻力位之上**（关键判断标准）
3. 有效突破，趋势继续
4. 可能伴随放量

**操作**：
- **动作**: 继续做多
- **止损**: 放在起涨点附近（88535）
- **逻辑**: 真突破表示趋势继续，应该跟随趋势
- **目标**: 可以看更高的位置

**示例**：
```
阻力位: 89354
价格突破: 89400
收盘价: 89500（真突破，收线突破）
操作: 继续做多
止损: 88535（起涨点附近）
```
