# 机器学习信号预测功能说明

## 功能概述

系统现在支持使用机器学习模型来预测交易信号的成功率，帮助筛选更有潜力的信号。

## 核心功能

### 1. 模型训练
- 基于历史已完成的信号数据训练预测模型
- 使用随机森林分类器（Random Forest）
- 自动特征提取和编码
- 自动评估模型性能

### 2. 信号预测
- 对新生成的信号预测成功率
- 返回成功概率、预测结果和置信度
- 可以用于筛选高质量信号

### 3. 模型管理
- 自动保存和加载模型
- 支持模型更新和再训练
- 记录模型元数据

## 使用方法

### 1. 训练模型

```python
from src.signal_tracker import SignalTracker
from src.ml_signal_predictor import MLSignalPredictor

# 加载信号数据
tracker = SignalTracker()
signals_data = tracker.load_signals()

# 训练模型
predictor = MLSignalPredictor()
result = predictor.train_model(signals_data)

print(f"模型准确率: {result['accuracy']:.2%}")
print(f"训练样本数: {result['train_samples']}")
print(f"特征重要性: {result['feature_importance']}")
```

### 2. 预测信号成功率

```python
# 预测新信号
signal = {
    'system': 'de',
    'timeframe': '5分钟',
    'entry_model': 'FVG回填',
    'type': 'long',
    'strength': 'strong',
    'entry': 87500,
    'stop_loss': 87000,
    'take_profit_1': 88000,
    'take_profit_2': 88500
}

prediction = predictor.predict_signal_success(signal)
print(f"成功概率: {prediction['success_probability']:.2%}")
print(f"预测结果: {'成功' if prediction['prediction'] == 1 else '失败'}")
print(f"置信度: {prediction['confidence']:.2%}")
```

## 特征说明

模型使用以下特征进行预测：

### 数值特征
- `stop_loss_distance_pct`: 止损距离（百分比）
- `tp1_distance_pct`: 第一止盈距离（百分比）
- `tp2_distance_pct`: 第二止盈距离（百分比）
- `risk_reward_ratio`: 盈亏比

### 分类特征
- `system`: 系统名称（de、meng等）
- `timeframe`: 时间框架（5分钟、15分钟等）
- `entry_model`: 入场模型（FVG、Vegas、Pinbar等）
- `type`: 交易方向（long、short）
- `strength`: 信号强度（strong、medium、weak）

## 模型性能

- **算法**: 随机森林分类器（Random Forest）
- **优点**: 
  - 处理非线性关系
  - 提供特征重要性
  - 对缺失值不敏感
  - 不容易过拟合
- **要求**: 至少10个已完成的信号才能训练模型

## 集成到系统

### 自动训练（建议）

在统一系统中集成自动训练功能：

```python
# 在统一系统中，定期（例如每100个新信号）重新训练模型
if completed_signals_count >= 100:
    predictor.train_model(signals_data)
```

### 信号评分

在生成新信号时使用模型评分：

```python
# 对每个新信号预测成功率
for signal in new_signals:
    prediction = predictor.predict_signal_success(signal)
    signal['ml_score'] = prediction['success_probability']
    signal['ml_confidence'] = prediction['confidence']
    
# 按ML分数排序，优先展示高分信号
new_signals.sort(key=lambda x: x.get('ml_score', 0), reverse=True)
```

## 注意事项

1. **数据要求**: 
   - 至少需要10个已完成的信号才能训练模型
   - 数据越多，模型越准确

2. **模型更新**:
   - 建议定期重新训练模型（例如每100个新信号）
   - 新数据会改善模型性能

3. **特征工程**:
   - 当前使用基础特征
   - 未来可以添加更多特征（如市场波动率、成交量等）

4. **模型选择**:
   - 当前使用随机森林
   - 如果数据量大，可以考虑XGBoost或LightGBM
