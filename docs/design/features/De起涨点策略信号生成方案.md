# De.起涨点策略信号生成方案

## 📋 策略信号生成能力分析

### 可以自动化的部分 ✅

1. **起涨点识别**
   - 自动找到最近一段时间内的最低点
   - 可以设置为最近N根K线的最低价

2. **阻力位识别**
   - 自动找到最近一段时间内的最高点
   - 或者识别关键阻力位

3. **价格突破检测**
   - 检测价格是否突破阻力位
   - 检测收盘价是否在阻力位上方

4. **止盈位置计算**
   - 自动计算10%和20%的止盈位置
   - 基于起涨点和阻力位的区间

5. **基本信号生成**
   - 生成"突破信号"（真突破或假突破）
   - 生成"次高信号"（未能突破）

### 需要手动判断的部分 ⚠️

1. **"次高"的判断**
   - 需要经验判断价格是否真的形成次高
   - 需要观察价格行为，不能完全自动化

2. **"用力空"的决策**
   - 需要判断市场情绪和整体趋势
   - 需要结合其他因素

3. **手动走一半的时机**
   - 需要根据实时市场情况判断
   - 需要观察价格行为和波动

4. **加回仓位的时机**
   - 需要判断"回马枪"后是否真的突破
   - 需要观察市场反应

5. **灵活调整**
   - 根据市场变化调整策略
   - 需要交易者的经验和判断

## 🎯 结论：两者结合

**信号生成方式**：**自动化信号 + 手动操作指导**

系统可以生成初步信号，但关键决策需要交易者手动判断和执行。

    "contingency": "..."      # 如何应对变化

## 📝 操作指导内容设计

### 1. 如何识别（Identification）

**内容**：
- 当前市场状态描述
- 起涨点和阻力位的位置
- 价格当前的表现
- 信号类型的说明

**例子**（假突破信号）：
```
【识别要点】
- 起涨点：88535（标记在图表上）
- 阻力位：89354（标记在图表上）
- 当前价格：89400（盘中突破89354）
- 收盘价：89350（在89354下方）
- 信号类型：假突破（扫了）

【关键判断】
✅ 价格盘中突破阻力位89354
❌ 但收盘价89350在阻力位下方
✅ K线可能形成上影线
→ 这是典型的假突破信号
```

### 2. 如何准备（Preparation）

**内容**：
- 需要标记的关键价位
- 需要计算的数值
- 交易计划要点
- 风险控制设置

**例子**：
```
【准备工作】
1. 标记关键价位：
   - 起涨点：88535（画水平线）
   - 阻力位：89354（画水平线）
   - 止盈目标：88699（20%位置，画水平线）

2. 计算数据：
   - 总区间：819点（89354 - 88535）
   - 10%止盈：88617
   - 20%止盈：88699
   - 止损位置：89400（阻力位上方）

3. 交易计划：
   - 方向：做空
   - 入场：89350附近（收盘价）
   - 止损：89400
   - 目标：88699（20%位置）
   - 仓位：小仓位测试

4. 风险控制：
   - 设置止损单
   - 如果价格重新突破89354并收盘站稳，立即止损
```

### 3. 如何操作（Action）

**内容**：
- 具体的操作步骤
- 入场时机
- 止损和目标设置
- 仓位管理

**例子**：
```
【操作步骤】
1. 等待当前K线收盘确认
   - 确认收盘价在89354下方
   - 确认K线形成上影线

2. 立即做空
   - 入场价位：89350（收盘价附近）
   - 或者等待下一个K线开盘

3. 设置止损和目标
   - 止损：89400（阻力位上方）
   - 目标：88699（20%位置）
   - 使用止损单和目标单

4. 监控价格
   - 观察价格是否按预期下跌
   - 如果价格重新突破89354，准备止损
```

### 4. 如何应对变化（Contingency）

**内容**：
- 如果判断错误怎么办
- 如果市场变化怎么办
- 部分平仓的策略
- 加回仓位的条件

**例子**：
```
【应对策略】
1. 如果价格重新突破89354：
   - 等待收盘确认
   - 如果收盘价在89354上方（真突破）
   - 立即止损空单
   - 考虑做多（真突破信号）

2. 如果价格继续下跌：
   - 到达88699目标位置，可以考虑止盈
   - 或者部分止盈，留一部分看更低位置

3. 手动走一半（可选）：
   - 如果价格快速下跌到89000附近
   - 可以考虑手动平掉一半仓位
   - 锁定部分利润
   - 剩余仓位继续持有到目标位置

4. 如果价格在目标位置反弹：
   - 观察是否形成新的起涨点
   - 如果反弹强烈，考虑提前止盈
```
