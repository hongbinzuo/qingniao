# 图表形态识别功能说明

## ✅ 已完成的功能

### 1. 完整的图表形态识别模块 ✅

**文件**: `src/chart_patterns_detector.py`

**支持的形态**:

#### 反转形态
- **头肩顶/底** (Head and Shoulders Top/Bottom)
- **双顶/底** (Double Top/Bottom)
- **三重顶/底** (Triple Top/Bottom)
- **圆顶/底** (Rounding Top/Bottom)

- **牛楔/熊楔** (Bull/Bear Pennant)

### 2. 完整的交易信息 ✅

每个识别到的形态都提供：
- **Entry（入场点）**: 基于形态的突破点或确认点
- **Stop Loss（止损）**: 基于形态结构的关键价位
- **Take Profit（止盈）**: 基于形态高度计算的目标位
- **Confidence（置信度）**: 形态识别的可靠性评分

- 在5分钟和15分钟时间框架都进行形态识别
- 识别到的形态自动转换为交易信号，包含完整的Entry/SL/TP信息

### 4. 报告显示 ✅

- 单独章节显示图表形态识别结果
- 按时间框架分类（5分钟/15分钟）
- 显示每个形态的完整交易信息

## 📊 形态识别逻辑

### 头肩顶/底
- **识别方法**: 寻找3个峰值/谷值，头部最高/最低，左右肩相似
- **入场**: 价格突破/跌破颈线
- **止损**: 右肩上方/下方
- **止盈**: 头部到颈线距离的0.618倍

### 双顶/底
- **识别方法**: 寻找2个相近的峰值/谷值
- **入场**: 价格突破/跌破颈线
- **止损**: 较高峰值上方/较低谷值下方
- **止盈**: 形态高度的0.618倍

### 三角形
- **上升三角形**: 水平阻力 + 上升支撑
- **下降三角形**: 水平支撑 + 下降阻力
- **入场**: 突破边界线
- **止损**: 另一边界外
- **止盈**: 基于形态宽度

### 旗形/楔形
- **识别方法**: 强趋势（旗杆）+ 整理区间（旗面）
- **入场**: 突破/跌破整理区间
- **止损**: 旗面另一端
- **止盈**: 旗杆高度的0.618倍

## 🔧 使用方法

### 自动使用

系统会自动：
1. 在每个时间框架分析K线数据
2. 识别所有可能的图表形态
3. 将形态转换为交易信号
4. 与现有技术分析信号合并
5. 选择最强的信号显示

### 查看结果

生成的交易信号报告中会包含：
- **主要信号**: 从所有信号（包括形态信号）中选择最强的
- **图表形态识别章节**: 详细列出所有识别到的形态及其交易建议

## 🔍 算法说明

### 摆动点识别

使用 `find_swing_points()` 方法识别价格的关键转折点：
- 峰值：当前高点比前后lookback个K线都高
- 谷值：当前低点比前后lookback个K线都低

### 形态匹配

- 基于摆动点序列匹配形态特征
- 使用价格差异百分比判断相似性
- 计算形态的对称性和清晰度来评估置信度

### 交易点位计算

- **Entry**: 基于形态的关键突破点
- **Stop Loss**: 放在形态结构的关键价位外
- **Take Profit**: 使用斐波那契比例（0.618）计算目标位
