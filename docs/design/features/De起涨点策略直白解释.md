# De.起涨点突破策略 - 直白解释版

## 🎯 一句话总结

**找到价格开始上涨的起点（起涨点），看价格能不能突破高点，如果突破失败就做空，如果真突破就继续做多。**

---

## 📖 用人话说这个策略

### 第一步：找到两个关键价格

想象你在看一张价格走势图：

1. **起涨点（比如88535）**
   - 这就是价格开始上涨的**起点**
   - 就像爬山时山脚的位置
   - 这是你的**安全线**，跌破这里就危险了

2. **高点（比如89354）**
   - 这就是价格想要到达的**目标**
   - 就像山顶的位置
   - 价格需要突破这里才能继续上涨

### 第二步：看价格怎么走

价格从起涨点（88535）开始往高点（89354）走，只有三种可能：

#### 情况1：突破失败，价格掉下来

**发生了什么**：
- 价格从88535开始涨
- 但是涨到某个位置（比如89200）就涨不动了
- 没能突破89354这个高点
- 然后价格开始掉下来

**你该怎么做**：
- 等价格跌破起涨点88535
- **立即做空**（卖出）
- 因为上涨失败了，接下来可能会跌

**关键词**：这叫"次高"，意思是没能突破高点，形成了第二个高点

#### 情况2：假突破（骗人的突破）

**发生了什么**：
- 价格从88535开始涨
- 价格短暂突破了89354（比如涨到89400）
- 但是你仔细看，收盘价又掉回89354以下了
- 这说明突破是假的，是在骗你

**你该怎么做**：
- **立即做空**（卖出）
- 目标是**起涨点上面一点**（大约88699的位置）
- 为什么是这个位置？因为这是起涨点和高点之间20%的位置，这是一个关键价位

**关键词**：这叫"假突破"或"扫了"，就是价格冲上去又掉下来了

#### 情况3：真突破（真的突破了）

**发生了什么**：
- 价格从88535开始涨
- 价格突破了89354
- **关键是：收盘价稳稳地站在89354上面**
- 这说明突破是真的

**你该怎么做**：
- **继续做多**（买入）
- 把止损放在起涨点88535附近
- 因为趋势继续向上，应该跟着趋势走

**关键词**：这叫"真突破"或"收线突破"，收盘价在阻力位上面才是真的突破

---

## 💰 "起涨点上面一点"是什么意思？

这是最容易被搞混的一句话。

### 简单理解

**起涨点（88535）到高点（89354）之间的距离是819点**

**"起涨点上面一点" = 起涨点 + 819点的10%到20%**

具体计算：
- **10%位置**：88535 + 82点 = **88617**
- **20%位置**：88535 + 164点 = **88699**

### 为什么是10%-20%？

De.说："正态分布，28定律，拍卖理论，斐波那契，最后结论都很相似"

**用简单话说**：
- 这些理论（数学方法）都在说同一个事情
- 就是在这个区间的10%-20%位置，是一个关键价位
- 价格容易在这个位置停下来或反弹

**你只需要记住**：
- 如果做空，目标就是起涨点上方10%-20%的位置
- 具体是88617（10%）或88699（20%）
- 选哪个看你的风险偏好（10%更保守，20%更激进）

## 🔑 最重要的三个判断

### 1. 收盘价是关键

**真假突破的区别就在收盘价**：
- ✅ 收盘价在89354上面 = 真突破，做多
- ❌ 收盘价在89354下面 = 假突破，做空

### 2. 起涨点是不能破的线

- 做多时，止损放在起涨点附近
- 如果跌破起涨点，说明趋势可能反转

### 3. 20%区间是关键价位

- 起涨点到高点的20%位置（约88699）是一个关键价位
- 做空时的目标位置
- 价格容易在这里停下来

De.说："现在晒单要这么晒，刚刚多单没止赢开了小空，用上了，目前88618还没损到，刚手动走了一半，如果这是回马枪，后面突破，把手动的加回"

**翻译成人话**：

2. **开了小空**：看到可能是假突破，所以开了小空
3. **手动走一半**：为了降低风险，手动平掉了一半仓位
4. **留后路**：如果后来发现是真突破，就把刚才平掉的仓位加回来

**关键点**：
- 不要一次性全部买入或卖出
- 根据市场情况灵活调整
- 保护好自己的本金（止损）

## 🎓 这个策略的核心思想

### 1. 找到关键价格点
- 起涨点 = 安全线
- 高点 = 目标线

### 2. 判断突破真假
- 看收盘价，不是看盘中价格
- 收盘价在阻力位上面 = 真突破
- 收盘价在阻力位下面 = 假突破

### 3. 根据判断行动
- 真突破 → 继续做多
- 假突破 → 立即做空
- 次高失败 → 跌破起涨点后做空

### 4. 灵活应对
- 不要死守，根据市场变化调整
- 可以分批操作（比如走一半）
- 如果判断错了，要能及时调整（比如加回仓位）
