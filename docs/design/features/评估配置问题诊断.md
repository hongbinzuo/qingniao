# 评估配置问题诊断

## 问题现象
评估统计显示：`评估信号数: 0`，`平均分数: 0.0/100`

## 根本原因分析

### 1. 评估执行流程
```
信号生成 → Markdown解析 → Brooks验证 → 自动评估 → 回测执行
```

### 2. 评估条件检查清单

#### ✅ 信号会被评估的条件：
1. **Markdown解析成功**
   - 文件格式正确
   - 包含币种名称（`## SYMBOL`）
   - 包含时间框架（`### X分钟信号`）
   - 包含入场价、止损、止盈1

2. **Brooks验证通过**
   - 止损位置正确
   - 盈亏比 ≥ 2:1
   - 符合趋势交易原则

3. **自动评估器可用**
   - `AutoEvaluator` 已初始化
   - 没有导入错误

#### ❌ 信号会被跳过评估的条件：
1. **Markdown解析失败**
   - 错误信息：`未找到有效信号`
   - 检查：文件格式是否正确

2. **Brooks验证失败**
   - 错误信息：`Brooks规则验证失败`
   - 检查：止损位置、盈亏比等

3. **自动评估器不可用**
   - 错误信息：`自动评估失败`
   - 检查：模块导入是否成功

### 3. 统计收集问题

#### 问题1: 字段名不匹配
- **期望**: `total_evaluated`
- **实际**: `total_signals`
- **状态**: ✅ 已修复（添加了 `total_evaluated` 字段）

#### 问题2: 评估历史为空
- **原因**: `AutoEvaluator.evaluation_history` 可能为空
- **检查**: 评估结果是否被保存（第118行：`self.evaluation_history.append(evaluation)`）
- **状态**: ✅ 代码已正确保存

#### 问题3: 统计收集逻辑错误
- **原因**: `evaluate_and_backtest` 从错误的字段获取统计
- **修复**: ✅ 已修复，现在从 `evaluation_stats` 获取
