# 全自动信号生成与评估系统说明

**创建时间**: 2026-01-14  
**功能**: 完全自动化的交易信号生成、评估和反馈系统

---

## 一、系统功能

### 1.1 核心功能

1. **自动生成信号**
   - 每隔指定时间（默认1小时）自动生成交易信号
   - 支持Top N币种（默认30个，按市值排序）
   - 支持多个时间框架（默认5m, 15m）
   - 使用模式匹配、Brooks规则、时间周期风险计算器

2. **自动评估**
   - 使用AutoEvaluator评估每个信号的质量
   - 评分系统（0-100分）
   - 质量等级分类

3. **自动回测**
   - 运行回测验证信号表现
   - 收集回测结果
   - 分析成功/失败原因

4. **反馈循环**
   - 将评估和回测结果收集到FeedbackLoop
   - 自动分析问题模式
   - 生成系统改进建议

5. **状态报告**
   - 实时状态显示
   - 生成历史记录
   - 总结报告

## 二、使用方法

### 2.1 启动系统

#### Windows
```bash
# 启动后台进程（每小时生成一次）
scripts\start_auto_signal_generator.bat

# 或手动启动
python scripts/auto_signal_generator.py --interval 1.0 --coins 30
```

#### Linux/macOS
```bash
# 后台运行
nohup python3 scripts/auto_signal_generator.py --interval 1.0 --coins 30 > outputs/logs/auto_signal_generator.log 2>&1 &
```

### 2.2 查看状态

```bash
# 查看当前状态和历史记录
python scripts/show_auto_signal_status.py
```

### 2.3 停止系统

#### Windows
```bash
scripts\stop_auto_signal_generator.bat
```

#### Linux/macOS
```bash
# 查找进程
ps aux | grep auto_signal_generator

# 停止进程
kill <PID>
```

## 三、配置参数

### 3.1 命令行参数

- `--interval`: 生成间隔（小时），默认1.0
- `--coins`: 币种数量，默认30（Top 30市值币种）
- `--timeframes`: 时间框架（逗号分隔），默认"5m,15m"
- `--once`: 只运行一次，不持续运行

### 3.2 示例

```bash
# 每2小时生成一次，Top 20币种
python scripts/auto_signal_generator.py --interval 2.0 --coins 20

# 只运行一次，Top 5币种
python scripts/auto_signal_generator.py --once --coins 5

# 自定义时间框架
python scripts/auto_signal_generator.py --timeframes "5m,15m,1h"
```

## 四、输出文件

### 4.1 交易计划

- **位置**: `outputs/trading_plans/auto_generated_YYYYMMDD_HHMMSS.md`
- **内容**: 生成的交易信号详情

### 4.2 状态文件

- **当前状态**: `outputs/auto_signal_status/current_status.json`
- **生成历史**: `outputs/auto_signal_status/generation_history.json`
- **总结报告**: `outputs/auto_signal_status/summary_YYYYMMDD_HHMMSS.md`

### 4.3 反馈报告

- **评估报告**: `outputs/feedback/continuous_evaluation_*.md`
- **改进建议**: `outputs/feedback/improvements_*.json`

### 4.4 日志文件

- **标准输出**: `outputs/logs/auto_signal_generator.log`
- **错误日志**: `outputs/logs/auto_signal_generator_error.log`

## 五、工作流程

```
1. 系统启动
   ↓
2. 初始化组件（模式匹配器、评估器、反馈循环等）
   ↓
3. 等待指定间隔时间
   ↓
4. 获取Top N币种列表
   ↓
5. 为每个币种生成交易信号
   - 获取K线数据
   - 模式匹配
   - 计算止损/止盈（使用时间周期风险计算器）
   - 获取Brooks概率
   ↓
6. 生成交易计划报告
   ↓
7. 评估和回测信号
   - 自动评估信号质量
   - 运行回测
   - 收集反馈
   ↓
8. 生成总结报告
   ↓
9. 保存状态和历史
   ↓
10. 返回步骤3（持续运行）
```

## 八、注意事项

1. **资源消耗**
   - 系统会持续运行，占用一定CPU和内存
   - 建议在服务器或专用机器上运行

2. **网络要求**
   - 需要访问Gate.io API获取价格数据
   - 确保网络连接稳定

3. **存储空间**
   - 会持续生成报告文件
   - 定期清理旧文件（保留最近100次记录）

4. **错误处理**
   - 系统会自动处理大部分错误
   - 严重错误会记录到错误日志
   - 建议定期检查日志
