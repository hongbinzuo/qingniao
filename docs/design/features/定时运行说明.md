# 定时运行说明

## 当前状态

### ✅ 梦多空策略
- **支持定时运行**：可以通过 `--interval` 参数设置定时
- **默认**：每2小时扫描一次
- **使用方式**：
  ```bash
  # 每2小时自动扫描（默认）
  python src/scan_meng_duo_kong_strategy.py --interval 2
  
  # 每4小时自动扫描
  python src/scan_meng_duo_kong_strategy.py --interval 4
  
  # 只扫描一次
  python src/scan_meng_duo_kong_strategy.py --interval 0
  ```

### ✅ 统一交易系统（已更新）
- **支持定时运行**：可以通过 `--interval` 参数设置定时
- **使用方式**：
  ```bash
  # 每2小时运行所有系统
  python src/unified_trading_system.py --system all --interval 2
  
  # 每4小时运行所有系统
  python src/unified_trading_system.py --system all --interval 4
  
  # 只运行一次（默认）
  python src/unified_trading_system.py --system all --interval 0
  ```

### ⚠️ De.系统
- **不支持定时运行**：需要手动调用或使用系统定时任务
- **原因**：De.系统分析BTC，通常需要手动查看信号

## 推荐的定时运行方案

### 方案1：使用统一系统定时运行（推荐）

**优点**：同时运行两个系统，统一管理

```bash
# 每2小时运行所有系统
python src/unified_trading_system.py --system all --interval 2
```

**后台运行**（Windows PowerShell）：
```powershell
Start-Process python -ArgumentList "src/unified_trading_system.py --system all --interval 2" -WindowStyle Hidden
```

### 方案2：只定时运行梦多空策略

**优点**：梦多空策略需要频繁扫描，De.系统可以手动运行

```bash
# 每2小时扫描涨幅榜
python src/scan_meng_duo_kong_strategy.py --interval 2
```

### 方案3：使用系统定时任务（Windows任务计划程序）

**优点**：即使程序关闭也能运行

#### Windows任务计划程序设置

1. 打开"任务计划程序"（Task Scheduler）

2. 创建基本任务
   - 名称：统一交易系统定时运行
   - 描述：每2小时运行De.系统和梦多空策略

3. 触发器设置
   - 选择"每天"
   - 开始时间：当前时间
   - 重复任务：每2小时，持续时间：无限期

4. 操作设置
   - 操作：启动程序
   - 程序或脚本：`python`
   - 添加参数：`src/unified_trading_system.py --system all --interval 0`
   - 起始于：`C:\Users\zuoho\code\qimeng2`

**注意**：使用系统定时任务时，`--interval` 应该设置为 `0`（只运行一次），由系统定时任务控制运行频率。

#### Linux/Mac cron设置

```bash
# 编辑crontab
crontab -e

# 每2小时运行一次（在每小时的0分和30分运行，实际是每2小时一次）
0 */2 * * * cd /path/to/qimeng2 && python src/unified_trading_system.py --system all --interval 0

# 或者使用梦多空策略的定时功能
0 */2 * * * cd /path/to/qimeng2 && python src/scan_meng_duo_kong_strategy.py --interval 2
```

## 实际使用建议

### 场景1：自动化交易信号生成（推荐）

```bash
# 启动统一系统，每2小时自动运行
python src/unified_trading_system.py --system all --interval 2
```

**特点**：
- ✅ 自动运行两个系统
- ✅ 每次运行生成最新的交易信号
- ✅ 可以一直运行，直到手动停止（Ctrl+C）

### 场景2：需要保持程序运行

如果您想让程序一直运行在后台：

**Windows**：
```powershell
# 在后台运行
Start-Process python -ArgumentList "src/unified_trading_system.py --system all --interval 2" -WindowStyle Hidden

# 或者使用nohup（如果有WSL）
nohup python src/unified_trading_system.py --system all --interval 2 > trading.log 2>&1 &
```

**Linux/Mac**：
```bash
# 使用nohup后台运行
nohup python src/unified_trading_system.py --system all --interval 2 > trading.log 2>&1 &

# 查看日志
tail -f trading.log
```

### 场景3：按需手动运行

如果您希望手动控制运行时机：

```bash
# 需要时手动运行一次
python src/unified_trading_system.py --system all
```

## 运行频率建议

### 梦多空策略
- **推荐频率**：每2小时（策略文档建议每小时扫描）
- **原因**：涨幅榜变化较快，需要及时捕捉机会

### De.系统（BTC分析）
- **推荐频率**：每4-6小时或按需
- **原因**：BTC走势相对稳定，不需要太频繁分析

### 统一系统
- **推荐频率**：每2-4小时
- **如果两个系统都要运行**：可以每2小时运行统一系统，或者分别设置不同频率

## 注意事项

1. **API限制**：注意不要设置过短的运行间隔，避免触发API限制
2. **资源消耗**：定时运行会持续占用资源，确保电脑不睡眠
3. **日志查看**：建议将输出重定向到日志文件，方便查看
4. **错误处理**：如果程序异常退出，需要重新启动
