# De.起涨点策略 - 5分钟15分钟实战指南

## 📋 适用场景

本指南专门针对**5分钟和15分钟短线交易**，告诉你如何在实际交易中应用De.的起涨点突破策略。

---

## 🎯 策略概览

### 核心流程（简化版）

```
1. 找到起涨点和阻力位
2. 观察价格是否突破
3. 判断真假突破（看收盘价）
4. 根据判断执行操作
5. 设置止损和目标
6. 灵活应对市场变化
```

---

## 📊 第一步：如何识别起涨点和阻力位

### 在5分钟图上识别

#### 1. 识别起涨点

**方法**：
- 在5分钟图上，找到最近一段时间内的**最低点**
- 这个最低点就是起涨点
- 价格从这个点开始上涨

**例子**：
- 如果最近1-2小时内的最低点是88535
- 那么88535就是起涨点

**技巧**：
- 起涨点通常是明显的低点
- 价格从这个点开始连续上涨
- 可以画一条水平线标记这个位置

#### 2. 识别阻力位（高点）

**方法**：
- 找到价格想要突破的**最高点**或**关键阻力位**
- 这个位置通常是：
  - 最近的高点
  - 之前价格多次没能突破的位置
  - 明显的阻力位

**例子**：
- 如果价格最近的高点是89354
- 而且价格多次尝试突破都没成功
- 那么89354就是阻力位

**技巧**：
- 阻力位通常是明显的峰值
- 可以画一条水平线标记
- 如果价格多次测试这个位置，说明这个阻力位很重要

### 在15分钟图上识别

**方法相同，但时间范围更大**：
- 15分钟图上的起涨点和阻力位通常更稳定
- 识别时间范围可以是最近几小时到一天
- 信号更可靠，但反应时间更长

## 🔍 第二步：如何准备交易

### 准备工作清单

#### 1. 标记关键价位
- ✅ 在图表上标记起涨点（画水平线）
- ✅ 在图表上标记阻力位（画水平线）
- ✅ 计算止盈位置（起涨点上方10%-20%）
- ✅ 计算止损位置（起涨点附近）

#### 2. 计算关键数据

**计算总区间**：
```
总区间 = 阻力位 - 起涨点
例如：89354 - 88535 = 819点
```

**计算止盈位置**：
```
10%止盈位置 = 起涨点 + 总区间 × 10%
20%止盈位置 = 起涨点 + 总区间 × 20%

例如：
10%止盈 = 88535 + 819 × 10% = 88617
20%止盈 = 88535 + 819 × 20% = 88699
```

**设置止损**：
```
做多止损 = 起涨点附近（如88535）
做空止损 = 阻力位上方一点（如89380）
```

#### 3. 制定交易计划

**计划要点**：
- 什么情况做多？（真突破）
- 什么情况做空？（假突破或次高失败）
- 目标价位是多少？（止盈位置）
- 止损价位是多少？
- 仓位大小？（建议小仓位测试）

## 🎮 第三步：如何操作

### 场景1：次高失败 + 跌破起涨点

#### 识别信号

**特征**：
1. 价格从起涨点开始上涨
2. 但没有突破阻力位
3. 形成次高点（低于阻力位）
4. 价格开始下跌
5. **跌破起涨点**

**例子**：
- 起涨点：88535
- 阻力位：89354
- 价格涨到：89200（形成次高，没突破89354）
- 价格跌到：88500（跌破起涨点88535）

#### 操作步骤

1. **确认跌破**
   - 等待价格明确跌破起涨点
   - 可以用5分钟或15分钟K线确认

2. **立即做空**
   - 入场价位：起涨点下方一点点（如88500）
   - 止损：阻力位上方（如89380）
   - 目标：可以看更低位置，或先看起涨点下方100-200点

3. **风险控制**
   - 设置止损单
   - 不要重仓
   - 如果反弹回起涨点上方，考虑止损

### 场景2：假突破

#### 识别信号

**特征**：
1. 价格从起涨点开始上涨
2. 价格**短暂突破**阻力位（盘中价格超过阻力位）
3. **但收盘价在阻力位下方**
4. K线形成上影线（冲上去又掉下来）

**关键判断**：**收盘价在阻力位下方才是假突破**

**例子**：
- 起涨点：88535
- 阻力位：89354
- 盘中最高：89400（突破了89354）
- 收盘价：89300（在89354下方）← 这是假突破

#### 操作步骤

1. **确认假突破**
   - 等待K线收盘
   - 确认收盘价在阻力位下方
   - 观察K线是否有长上影线

2. **立即做空**
   - 入场价位：收盘价附近（如89300）
   - 止损：阻力位上方（如89400）
   - **目标：起涨点上方10%-20%位置**
     - 10%目标：88617
     - 20%目标：88699

3. **风险控制**
   - 设置止损单
   - 如果价格重新突破阻力位并收盘站稳，考虑止损

### 场景3：真突破

#### 识别信号

**特征**：
1. 价格从起涨点开始上涨
2. 价格突破阻力位
3. **收盘价稳稳站在阻力位上方**
4. K线实体在阻力位上方

**关键判断**：**收盘价在阻力位上方才是真突破**

**例子**：
- 起涨点：88535
- 阻力位：89354
- 收盘价：89400（在89354上方）← 这是真突破

#### 操作步骤

1. **确认真突破**
   - 等待K线收盘
   - 确认收盘价在阻力位上方
   - 观察是否有放量（成交量增加）

2. **继续做多**
   - 入场价位：收盘价附近或下一个K线开盘（如89400）
   - **止损：起涨点附近**（如88535）
   - 目标：可以看更高位置，或者使用其他技术分析确定目标

3. **风险控制**
   - 设置止损单（非常重要！）
   - 如果价格跌回阻力位下方，考虑止损
   - 可以考虑分批止盈

## 🔄 第四步：如何应对变化

### 情况1：判断错了怎么办？

#### 做空后价格反而上涨

**应对**：
- 如果价格重新突破阻力位并收盘站稳
- **立即止损**
- 承认判断错误，不要死扛

#### 做多后价格反而下跌

**应对**：
- 如果价格跌回起涨点附近
- **止损**
- 如果跌破起涨点，必须止损

### 情况2：部分平仓后市场变化

**De.的操作方式**：
- "刚手动走了一半"
- "如果这是回马枪，后面突破，把手动的加回"

**应对策略**：

#### 做空后手动走一半
1. 如果价格继续下跌，剩余仓位继续盈利
2. 如果价格反弹（回马枪），然后真的突破阻力位
3. **把刚才平掉的仓位加回来**（做多）
4. 这样既能锁定部分利润，又能抓住新的机会

#### 做多后手动走一半
1. 如果价格继续上涨，剩余仓位继续盈利
2. 如果价格回调到起涨点附近
3. **可以加回仓位**（如果判断趋势还在）
4. 或者**全部平仓**（如果判断趋势可能反转）

### 情况3：回马枪（假突破后又真突破）

**识别**：
- 价格先假突破（收盘在阻力位下方）
- 你做了空
- 但价格又反弹回来
- 然后真的突破（收盘在阻力位上方）

**应对**：
- **立即止损空单**
- **开多单**（加回仓位）
- 因为这次可能是真突破了

## 📈 实战技巧

### 技巧1：结合多个时间框架

**5分钟 + 15分钟结合**：
- **15分钟图**：确定大方向和关键价位
- **5分钟图**：找具体的入场时机
- 如果15分钟图显示真突破，5分钟图出现入场机会，信号更可靠

### 技巧2：等待确认

**不要急于入场**：
- 等待K线收盘确认
- 特别是判断真假突破时，收盘价是关键
- 宁愿错过，不要做错

### 技巧3：分批操作

**像De.一样灵活**：
- 不要一次性全仓
- 可以分批建仓
- 可以分批平仓
- 根据市场变化灵活调整

### 技巧4：止损必须设

**无论如何都要设止损**：
- 做多：止损在起涨点附近
- 做空：止损在阻力位上方
- 不要心存侥幸

## ✅ 操作检查清单

### 入场前检查

- [ ] 起涨点和阻力位已经标记
- [ ] 止盈位置已经计算（10%或20%）
- [ ] 止损位置已经确定
- [ ] 交易计划已经制定
- [ ] 仓位大小已经确定（建议小仓位）

### 入场时检查

- [ ] 信号已经确认（K线收盘）
- [ ] 判断是真突破还是假突破（看收盘价）
- [ ] 止损单已经设置
- [ ] 目标位置已经设定

### 持仓中检查

- [ ] 价格是否按预期方向走？
- [ ] 是否需要调整止损？
- [ ] 是否需要部分平仓？
- [ ] 市场是否有变化？

### 出场时检查

- [ ] 是否到达目标位置？
- [ ] 是否需要止盈？
- [ ] 是否需要止损？
- [ ] 是否需要加仓或减仓？

## 🎯 实战案例

### 案例1：假突破做空

**背景**：
- 起涨点：88535
- 阻力位：89354
- 5分钟图

**过程**：
1. 价格从88535上涨到89300
2. 盘中突破89354，最高到89400
3. 但收盘价是89300（在89354下方）
4. 判断：假突破

**操作**：
- 在89300做空
- 止损：89400（阻力位上方）
- 目标：88699（20%位置）
- 结果：价格下跌到88699，止盈

### 案例2：真突破做多

**背景**：
- 起涨点：88535
- 阻力位：89354
- 15分钟图

**过程**：
1. 价格从88535上涨到89300
2. 价格突破89354，收盘价89450
3. 收盘价在89354上方
4. 判断：真突破

**操作**：
- 在89450做多
- 止损：88535（起涨点附近）
- 目标：看更高位置（如90000）
- 结果：价格继续上涨到90000，部分止盈

## 💡 重要提醒

1. **收盘价是关键**：真假突破的判断完全看收盘价
2. **起涨点不能破**：做多时，跌破起涨点必须止损
3. **灵活应对**：根据市场变化调整策略，不要死守
4. **保护本金**：止损必须设，不要心存侥幸
5. **小仓位开始**：先用小仓位练习，熟悉后再加大仓位
