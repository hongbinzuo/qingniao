## 🏗️ 系统架构

### 1. 视频分析模块

**功能**:
- 视频转录（使用YouTube API或本地转录）
- 文本分析（提取交易规则）
- 规则提取（NLP分析）
- 规则验证（与现有系统对比）

**技术栈**:
- YouTube API / yt-dlp（视频下载）
- Whisper / OpenAI Whisper（语音转文字）
- NLP分析（规则提取）
- 规则引擎（规则编码）

### 2. 图片分析模块

**功能**:
- 图片OCR（提取文字标注）
- 图表识别（识别K线、指标）
- 形态识别（识别交易形态）
- 标注提取（提取入场、止损、止盈标记）

**技术栈**:
- OCR（Tesseract / PaddleOCR）
- 图像识别（OpenCV / YOLO）
- 图表解析（自定义解析器）
- 标注提取（坐标识别）

### 3. 规则提取模块

**功能**:
- 规则结构化（将提取的内容结构化）
- 规则验证（验证规则完整性）
- 规则编码（转换为代码规则）
- 规则测试（回测验证）

### 4. 交易系统集成

**功能**:
- 信号生成（基于千叶规则）
- 信号评估（评估信号质量）
- 系统集成（集成到统一系统）
- 性能监控（监控系统表现）
