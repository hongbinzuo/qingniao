# 信号评估条件说明

## 评估流程

### 1. 信号解析
- **条件**: Markdown文件必须包含有效的信号格式
- **要求**: 
  - 必须有币种名称（`## SYMBOL`）
  - 必须有时间框架（`### X分钟信号`）
  - 必须包含入场价、止损、止盈1等关键信息

### 2. Brooks规则验证
- **条件**: 信号必须通过Brooks规则验证
- **验证项**:
  - 止损位置正确（做多止损在入场价下方，做空止损在入场价上方）
  - 盈亏比至少2:1
  - 符合趋势交易原则
  - 模式与方向一致
- **结果**: 
  - ✅ 通过：继续评估和回测
  - ❌ 失败：跳过，记录为"Brooks规则验证失败"

### 3. 自动评估（AutoEvaluator）
- **条件**: 信号通过Brooks验证后，进行自动评估
- **评估项**:
  - **基本有效性检查**:
    - 入场价、止损、止盈必须 > 0
    - 止损方向必须正确
    - 价格必须合理（不能为0或负数）
  
  - **止损位置评估**:
    - 5分钟信号：最低止损2%，理想止损2.5%
    - 15分钟信号：最低止损2.5%，理想止损3%
    - 止损距离过小会扣分
  
  - **盈亏比评估**:
    - 最低要求：2:1
    - 理想值：3:1
    - 低于2:1会标记为不可交易
  
  - **市场条件评估**:
    - 检查信号是否过期（如果提供了当前价格）
    - 评估市场波动性
    - 检查是否适合当前市场环境
  
  - **模式质量评估**:
    - 评估模式识别质量
    - 检查置信度
    - 评估Brooks概率评分

- **评估结果**:
  - **质量等级**:
    - `EXCELLENT` (优秀): 90-100分
    - `GOOD` (良好): 75-89分
    - `FAIR` (一般): 60-74分
    - `POOR` (较差): 40-59分
    - `INVALID` (无效): < 40分或基本验证失败
  
  - **可交易性**:
    - `is_tradable = True`: 信号可以交易
    - `is_tradable = False`: 信号不可交易（跳过回测）

### 4. 回测执行
- **条件**: 
  - 通过Brooks验证
  - 通过自动评估（`is_tradable = True`）
- **要求**:
  - 必须有历史价格数据
  - 信号参数完整
  - 数据库连接正常

## 评估条件总结

### 信号会被评估的条件：
1. ✅ Markdown文件格式正确
2. ✅ 信号参数完整（入场价、止损、止盈）
3. ✅ 通过Brooks规则验证
4. ✅ 自动评估器可用

### 信号会被跳过评估的条件：
1. ❌ Markdown解析失败
2. ❌ 信号参数不完整
3. ❌ Brooks规则验证失败
4. ❌ 自动评估器不可用

### 信号会被标记为不可交易的条件：
1. ❌ 基本验证失败（价格无效、止损方向错误）
2. ❌ 止损距离过小（5m < 2%, 15m < 2.5%）
3. ❌ 盈亏比 < 2:1
4. ❌ 信号已过期（如果提供了当前价格）
5. ❌ 评估分数 < 40分
