# 主力洗盘场景识别功能说明

## ✅ 已完成的功能

### 1. 完整的主力洗盘场景识别模块 ✅

**文件**: `src/main_force_washout_detector.py`

**实现的6种主力洗盘场景**:

1. ✅ **箱体震荡** (Box Oscillation)
   - 特征：维持矩形箱体震荡
   - 调整幅度不超过上涨的1/3
   - 两波上涨1:1等高
   - 突破上沿后做多

2. ✅ **三角形震荡** (Triangle Oscillation)
   - 特征：收敛三角形形态
   - 成交量不断缩量，三角形角的时候最低
   - 突破时必须放量
   - 两波上涨1:1等高

3. ✅ **五浪调整** (Five-Wave Adjustment)
   - 特征：5段走势，波浪式下跌
   - 破位下降趋势线必须放量
   - 调整一般是上涨的1/2
   - 两波上涨1:1等高

4. ✅ **旗形下跌** (Falling Flag)
   - 特征：旗子旗杆，调整缩量
   - 破位下降趋势线须放量
   - 调整一般是上涨的1/2
   - 两波上涨1:1等高

5. ✅ **缩量圆弧** (Volume Shrinking Arc)
   - 特征：圆弧型态调整
   - 成交量缩量
   - 放量开始进场
   - 两波上涨1:1等高

6. ✅ **旗形上涨** (Rising Flag)
   - 特征：旗子旗杆，上涨途中温和放量
   - 主力边拉升边洗盘
   - 后市加速
   - 两波上涨1:1等高

## 📊 使用场景

### 主要用途

1. **做多机会确认**
   - 当识别到多个洗盘场景时，确认做多机会
   - 结合其他技术分析，提高做多信号的可靠性
   - 建议：当做多机会强度>50%时，考虑做多

2. **洗盘后入场**
   - 识别主力洗盘后的突破机会
   - 在洗盘结束、突破确认后入场
   - 避免在洗盘过程中过早入场

3. **趋势延续确认**
   - 确认上涨趋势中的整理阶段
   - 判断整理结束和趋势延续的信号
   - 在突破整理区间后入场

4. **风险管理**
   - 识别洗盘场景，避免在整理过程中频繁交易
   - 等待明确的突破信号后再入场
   - 根据场景强度调整仓位大小

## 🔧 技术实现

### 核心算法

1. **箱体震荡识别**
   - 检测矩形箱体（高点相近，低点相近）
   - 验证调整幅度不超过上涨的1/3
   - 检测突破上沿

2. **三角形震荡识别**
   - 检测收敛三角形（高点下降，低点上升）
   - 验证成交量缩量
   - 检测突破放量

3. **五浪调整识别**
   - 检测5段波浪式下跌
   - 验证调整幅度约上涨的1/2
   - 检测破位下降趋势线并放量

4. **旗形下跌识别**
   - 检测下降通道（旗面）
   - 验证调整缩量
   - 检测突破上沿并放量

5. **缩量圆弧识别**
   - 检测圆弧底部形态
   - 验证成交量缩量（底部最低）
   - 检测放量启动

6. **旗形上涨识别**
   - 检测上升通道（旗面）
   - 验证温和放量
   - 检测突破上沿

### 做多机会强度计算

- 基于识别到的场景数量
- 强度 = (识别到的场景数 / 6) × 100%
- 最多100%

## 🔍 算法说明

### 场景检测逻辑

每个场景都有独立的检测逻辑和强度评分：

1. **箱体震荡**: 基于矩形形态和调整幅度
2. **三角形震荡**: 基于收敛形态和成交量变化
3. **五浪调整**: 基于波浪结构和调整幅度
4. **旗形下跌**: 基于下降通道和成交量
5. **缩量圆弧**: 基于圆弧形态和成交量
6. **旗形上涨**: 基于上升通道和成交量

### 强度评分

- 每个场景都有独立的强度评分（0-100%）
- 整体做多机会强度 = (识别到的场景数 / 6) × 100%
- 强度越高，做多机会越明确

## 📈 与现有系统的整合

### 与其他识别模块配合

- **图表形态识别**: 识别具体的形态（如双底、头肩底等）
- **下降趋势识别**: 识别下降趋势特征（用于判断是否适合做多）
- **主力洗盘场景识别**: 识别洗盘后的做多机会（新增）

三者可以相互配合：
- 当图表形态识别到看涨形态时
- 下降趋势识别可以提供趋势确认
- 主力洗盘场景识别可以提供洗盘后的入场机会
- 三者结合，提高做多信号的可靠性

### 与现有技术分析配合

- **FVG信号**: 如果识别到上涨FVG + 洗盘场景确认 = 更强的做多信号
- **Vegas通道**: 如果价格在Vegas上方 + 洗盘场景确认 = 确认上升趋势
- **支撑阻力**: 如果价格在支撑位 + 洗盘场景确认 = 确认支撑有效性
