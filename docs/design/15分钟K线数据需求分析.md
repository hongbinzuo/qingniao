## API限制

### Binance API限制

- **单次请求最大limit**: 1,500根K线
- **如需更多数据**: 需要分次请求并合并

### 数据获取策略

1. **基本策略**: 单次请求1,500根（约15.6天）
2. **推荐策略**: 多次请求合并，获取至少90天（8,640根）
3. **理想策略**: 多次请求合并，获取180-365天（17,520-35,040根）

## 实现方案

### 方案1: 单次请求（当前实现）
- 限制: 最多1,500根（约15.6天）
- 优点: 简单快速
- 缺点: 数据量不足

### 方案2: 多次请求合并（推荐）
- 步骤:
  1. 计算需要的总K线数
  2. 计算需要的请求次数（每次1,500根）
  3. 从最远的时间点开始请求
  4. 合并所有请求结果
  5. 按时间排序去重

- 优点: 可以获取任意长度的数据
- 缺点: 需要多次请求，耗时稍长

## 推荐配置

对于15分钟时间框架，推荐：

- **最小数据量**: 10天（960根K线）
- **推荐数据量**: 30-90天（2,880-8,640根K线）
- **理想数据量**: 90-180天（8,640-17,520根K线）

这样可以匹配：
- 短期模式：10-30天
- 中期模式：30-90天（如Page 269）
- 长期模式：90-180天

## 实现细节

### 分次请求逻辑

```python
def get_kline_binance_extended(symbol, timeframe, days):
    """
    获取扩展的K线数据（支持超过1,500根的限制）
    
    Args:
        symbol: 交易对
        timeframe: 时间框架（如'15m'）
        days: 需要的天数
    
    Returns:
        K线数据列表（按时间从早到晚排序）
    """
    klines_per_day = 96  # 15分钟
    total_needed = days * klines_per_day
    max_per_request = 1500
    
    # 计算需要的请求次数
    num_requests = (total_needed + max_per_request - 1) // max_per_request
    
    all_klines = []
    end_time = None  # 第一次请求使用None（获取最新数据）
    
    for i in range(num_requests):
        limit = min(max_per_request, total_needed - len(all_klines))
        
        # 请求数据
        klines = get_kline_binance_single(symbol, timeframe, limit, end_time)
        
        if not klines:
            break
        
        # 如果是第一次请求，获取最新的数据
        if i == 0:
            all_klines = klines
            # 设置下一次请求的结束时间为最早的时间戳
            end_time = klines[0]['timestamp'] * 1000 - 1  # 转换为毫秒并减1
        else:
            # 合并数据（从早到晚）
            all_klines = klines + all_klines
            # 更新结束时间
            if klines:
                end_time = klines[0]['timestamp'] * 1000 - 1
        
        # 如果已经获取足够的数据，退出
        if len(all_klines) >= total_needed:
            break
    
    # 去重并排序
    seen = set()
    unique_klines = []
    for k in all_klines:
        ts = k['timestamp']
        if ts not in seen:
            seen.add(ts)
            unique_klines.append(k)
    
    # 按时间排序（从早到晚）
    unique_klines.sort(key=lambda x: x['timestamp'])
    
    # 只返回需要的数量
    return unique_klines[-total_needed:] if len(unique_klines) > total_needed else unique_klines
```

## 时区问题

用户使用北京时间（UTC+8），需要确保时间戳转换正确：

- Binance API返回的时间戳是UTC时间
- 显示时需要转换为北京时间（+8小时）
- 或者在匹配时统一使用UTC时间
