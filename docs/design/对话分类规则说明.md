# 对话分类规则说明

## 概述

青鸟系统需要准确区分De.对话中的**观点**和**交易记录**，以便：
- 正确存储和学习交易策略
- 区分理论观点和实际执行
- 特别处理包含图片的交易记录

## 分类体系

### 1. trading_execution（交易执行记录）

**定义**: 已完成或正在进行的交易记录

**特征**:
- 包含时间标记：`已经`、`目前`、`昨天`、`今天`、`刚才`
- 包含交易动作：`止盈了`、`止损了`、`吃了`、`拿下`、`成交了`
- 包含价格和执行细节：`扫了`、`追单`、`挂单`、`执行`
- 包含结果：`盈利`、`亏损`、`赚了`、`亏了`、`已经X点`、`目前X点`
- **包含截图/图片**: 更可能是交易记录

**示例**:
- "这单883止盈过"
- "已经200点的"
- "昨天扫了866下方，后面突上868追单目标是885，止盈第一883"
- "挂单87218止盈了部分剩下的留给876打止损"

### 2. trading_signal（交易信号/建议）

**定义**: 交易建议或计划，尚未执行

**特征**:
- 包含建议词：`可以`、`应该`、`建议`、`可以空`、`可以多`
- 包含判断词：`看起来`、`很好`、`机会`、`可以进`
- 包含计划：`目标`、`止损`、`止盈`、`挂`
- 包含条件：`如果...可以`、`如果...应该`
- 包含价格和交易方向

**示例**:
- "15分看起来很好空，撸上一把"
- "可以进空"
- "如果889吃完一小时后内收进884下面老实空进去吃到864"
- "可以挂保本吃100点"

### 3. viewpoint（观点和理论）

**定义**: 理论、逻辑、概念、策略理念

**特征**:
- 包含理论词：`理论`、`逻辑`、`道理`、`意义`、`概念`
- 包含判断词：`认为`、`觉得`、`应该`、`可能`、`大概`
- 包含绝对词：`永远`、`都是`、`不是`、`没有`
- 包含策略词：`策略`、`方法`、`方式`、`理念`
- 包含逻辑词：`因为`、`所以`、`但是`、`如果`
- 包含市场概念：`组织`、`庄家`、`巨鲸`、`市场`

**示例**:
- "预言是对未来趋势的判断，但是基本基础是价值"
- "没有价值，没有共情，没有市场信誉度的币子最后难逃归零的结局"
- "期权交割组织，知道这个消息的会提前空，然后被爆"
- "看币本位，油本位，意义不是很大"

### 4. conversation（一般对话）

**定义**: 不包含明确交易信息或观点的对话

**特征**:
- 不包含上述任何特征
- 一般性交流

## 分类优先级

1. **包含截图/图片** → 优先判断为 `trading_execution`
2. **时间标记 + 价格 + 交易动作** → `trading_execution`
3. **建议词 + 价格 + 交易动作** → `trading_signal`
4. **理论词 + 逻辑词** → `viewpoint`
5. **其他** → `conversation`

## 处理流程

### 1. 对话录入时

```python
def classify_content(content, has_screenshot=False):
    # 检查交易执行记录
    execution_score = sum(1 for kw in execution_keywords if re.search(kw, content))
    has_price_and_action = bool(re.search(r'\d{3,4}', content)) and (
        '止盈' in content or '止损' in content or '空' in content or '多' in content
    )
    
    # 如果有截图，更可能是交易记录
    if has_screenshot:
        execution_score += 2
    
    # 分类决策
    if execution_score >= 2 or (has_price_and_action and execution_score >= 1):
        return 'trading_execution'
    # ... 其他分类逻辑
```

### 2. 数据库存储

- 使用 `category` 字段存储分类
- 使用 `tags` 字段存储相关标签
- 使用 `has_screenshot` 标记是否包含图片

### 3. 查询和统计

```sql
-- 查询所有交易执行记录
SELECT * FROM trader_viewpoints 
WHERE category = 'trading_execution';

-- 查询所有交易信号
SELECT * FROM trader_viewpoints 
WHERE category = 'trading_signal';

-- 查询所有观点
SELECT * FROM trader_viewpoints 
WHERE category = 'viewpoint';
```

## 注意事项

1. **图片优先**: 包含图片的对话更可能是交易记录
2. **上下文重要**: 需要结合上下文判断，不能仅看关键词
3. **动态调整**: 分类规则需要根据实际情况不断优化
4. **人工审核**: 重要记录建议人工审核分类
