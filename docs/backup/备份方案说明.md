# 数据备份方案 - 安全低成本

## 📋 概述

本方案提供安全、低成本的数据库和文件备份解决方案，支持：
- ✅ 本地压缩备份
- ✅ 云存储备份（可选）
- ✅ 增量备份
- ✅ 自动清理旧备份
- ✅ 备份完整性验证

### 数据库文件（12个DuckDB文件）

## 🚀 快速开始

### 1. 运行备份脚本

```bash
python scripts/backup_data.py
```

### 2. 备份输出

备份文件保存在 `backups/backup_YYYYMMDD_HHMMSS/` 目录下：
- 数据库文件（压缩为 `.gz`）
- 数据目录（压缩为 `.tar.gz`）
- `backup_manifest.json` - 备份清单（包含文件哈希、大小等信息）

### 3. 查看备份清单

```bash
cat backups/backup_*/backup_manifest.json
```

## 💾 备份方案对比

### 方案1: 本地备份（推荐，免费）

**优点**:
- ✅ 完全免费
- ✅ 速度快
- ✅ 数据完全控制
- ✅ 支持压缩（节省空间）

**缺点**:
- ❌ 需要本地存储空间
- ❌ 单点故障风险

**适用场景**:
- 日常备份
- 快速恢复
- 小到中等数据量（< 100GB）

**实施**:
```bash
python scripts/backup_data.py
```

### 方案2: GitHub私有仓库 + Git LFS（低成本）

**优点**:
- ✅ 免费（私有仓库免费，LFS 1GB免费）
- ✅ 版本控制
- ✅ 自动同步
- ✅ 多设备访问

**缺点**:
- ❌ LFS超出1GB需要付费
- ❌ 需要Git知识

**适用场景**:
- 代码 + 小数据文件
- 需要版本历史
- 多设备协作

**实施**:
```bash
# 1. 安装Git LFS
git lfs install

# 2. 跟踪大文件
git lfs track "*.duckdb"
git lfs track "*.tar.gz"

# 3. 提交到私有仓库
git add .gitattributes
git commit -m "Add LFS tracking"
git push
```

### 方案3: 云存储（低成本）

#### 3.1 百度网盘 / 阿里云盘（免费）

**优点**:
- ✅ 免费（大容量）
- ✅ 简单易用
- ✅ 自动同步

**缺点**:
- ❌ 上传速度可能较慢
- ❌ 需要手动操作

**实施**:
1. 运行备份脚本
2. 手动上传 `backups/` 目录到云盘

#### 3.2 腾讯云COS / 阿里云OSS（按量付费）

**优点**:
- ✅ 价格低（约0.1元/GB/月）
- ✅ 速度快
- ✅ 可靠性高

**缺点**:
- ❌ 需要付费（但很便宜）
- ❌ 需要配置

**成本估算**:
- 假设备份文件10GB
- 存储费用: 10GB × 0.1元/GB/月 = 1元/月
- 下载费用: 按需付费（很少）

#### 3.3 AWS S3 / Google Cloud Storage（按量付费）

**优点**:
- ✅ 全球可用
- ✅ 可靠性极高
- ✅ 支持生命周期管理

**缺点**:
- ❌ 需要付费
- ❌ 配置较复杂

**成本估算**:
- S3标准存储: 约$0.023/GB/月
- 10GB备份: 约$0.23/月（约1.6元/月）

### 方案4: 混合备份（推荐，最安全）

**策略**:
1. **本地备份** - 日常快速备份（保留7天）
2. **云存储备份** - 每周备份一次（保留1个月）
3. **长期归档** - 每月备份一次（保留1年）

**优点**:
- ✅ 多层保护
- ✅ 快速恢复（本地）
- ✅ 灾难恢复（云存储）
- ✅ 成本可控

## 🔒 安全建议

### 1. 加密敏感数据

如果备份包含敏感信息（API密钥、交易记录等），建议加密：

```bash
# 使用7zip加密压缩
7z a -p密码 backup.7z backups/backup_*/
```

### 2. 访问控制

- 云存储设置访问权限
- 不要将备份文件提交到公开仓库
- 定期更换访问密钥

### 3. 验证备份完整性

备份脚本自动计算文件哈希，可以验证：

```python
import json
from pathlib import Path

manifest = json.loads(Path('backups/backup_*/backup_manifest.json').read_text())
# 验证文件哈希
```

## 📅 备份计划建议

### 日常备份（自动化）

```bash
# Windows任务计划程序
# 每天凌晨2点运行
python scripts/backup_data.py
```

### 周备份（手动或自动化）

```bash
# 每周日备份到云存储
python scripts/backup_data.py
# 然后上传到云盘
```

### 月备份（归档）

```bash
# 每月1号创建归档备份
python scripts/backup_data.py
# 重命名为 archive_YYYYMM.tar.gz
# 上传到长期存储
```

## 🛠️ 恢复数据

### 从本地备份恢复

```bash
# 1. 解压数据库文件
gunzip backups/backup_*/qingniao_abu.duckdb.gz
cp backups/backup_*/qingniao_abu.duckdb src/data/

# 2. 解压数据目录
tar -xzf backups/backup_*/data_abu_images.tar.gz -C data/
```

### 从云存储恢复

1. 下载备份文件
2. 解压到项目目录
3. 验证文件完整性

## 🔧 故障排除

### 问题1: 备份文件太大

**解决方案**:
- 启用压缩（默认已启用）
- 排除不必要的数据目录
- 使用增量备份

### 问题2: 备份速度慢

**解决方案**:
- 只备份重要文件
- 使用SSD存储
- 并行备份多个文件

### 问题3: 云存储上传失败

**解决方案**:
- 检查网络连接
- 使用断点续传工具
- 分批上传大文件
