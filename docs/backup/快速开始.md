# 备份快速开始指南

## 🚀 一键备份

### 1. 本地备份（推荐）

```bash
# 运行备份脚本
python scripts/backup_data.py
```

**输出**:
- 备份文件保存在 `backups/backup_YYYYMMDD_HHMMSS/`
- 自动压缩（节省空间）
- 自动清理7天前的旧备份
- 生成备份清单（包含文件哈希）

### 2. 查看备份结果

```bash
# 查看最新备份
dir backups\backup_* /O-D

# 查看备份清单
type backups\backup_*\backup_manifest.json
```

### 3. 上传到云存储（可选）

#### 方案A: 手动上传（最简单）

1. 运行备份脚本
2. 打开云盘（百度网盘/阿里云盘）
3. 上传 `backups/backup_最新日期/` 文件夹

#### 方案B: 自动上传（需要配置）

```bash
# 上传到腾讯云COS（需要配置）
python scripts/backup_to_cloud.py backups/backup_20260111_120000 --service tencent_cos --config config/cloud_backup.json
```

## 🔒 安全建议

1. **敏感数据加密**:
   ```bash
   # 使用7zip加密
   7z a -p你的密码 backup.7z backups/backup_*/
   ```

2. **定期验证备份**:
   - 检查备份清单中的文件哈希
   - 定期测试恢复流程

3. **多地点备份**:
   - 本地 + 云存储
   - 至少保留2个备份副本

## 🛠️ 恢复数据

### 从备份恢复数据库

```bash
# 1. 解压数据库文件
gunzip backups/backup_*/qingniao_abu.duckdb.gz

# 2. 复制到原位置
copy backups\backup_*\qingniao_abu.duckdb src\data\
```

### 从备份恢复数据目录

```bash
# 解压数据目录
tar -xzf backups/backup_*/data_abu_images.tar.gz -C data/
```

## ❓ 常见问题

**Q: 备份文件太大怎么办？**
A: 脚本已自动压缩，通常可节省50-70%空间。

**Q: 可以只备份部分文件吗？**
A: 修改 `scripts/backup_data.py` 中的 `DATABASE_FILES` 和 `DATA_DIRS`。

**Q: 备份需要多长时间？**
A: 取决于数据量，通常1-10分钟。

**Q: 如何验证备份完整性？**
A: 检查 `backup_manifest.json` 中的文件哈希值。
