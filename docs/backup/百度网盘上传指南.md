# 百度网盘备份上传指南

## 📋 概述

本指南说明如何将本地备份上传到百度网盘，实现双重保护。

## 🚀 快速步骤

### 1. 运行本地备份

```bash
python scripts/backup_data.py
```

备份文件会保存在 `backups/backup_YYYYMMDD_HHMMSS/` 目录下。

### 2. 上传到百度网盘

#### 方法A: 网页版上传（推荐，简单）

1. **打开百度网盘网页版**
   - 访问: https://pan.baidu.com
   - 登录账号

2. **创建备份文件夹**
   - 在网盘中创建文件夹: `qingniao_backups`
   - 建议按日期创建子文件夹: `2026-01-11`

3. **上传备份文件**
   - 进入备份文件夹
   - 点击"上传"按钮
   - 选择本地备份目录: `backups/backup_YYYYMMDD_HHMMSS/`
   - 等待上传完成

#### 方法B: 客户端上传（推荐，速度快）

1. **下载百度网盘客户端**
   - 访问: https://pan.baidu.com/download
   - 下载并安装客户端

2. **登录客户端**

3. **上传备份**
   - 在客户端中创建文件夹: `qingniao_backups/2026-01-11`
   - 拖拽本地备份文件夹到客户端
   - 等待上传完成

#### 方法C: 使用API自动上传（高级，需要配置）

需要申请百度网盘API，配置较复杂，不推荐普通用户使用。

## 📁 推荐的文件夹结构

在百度网盘中建议按以下结构组织：

```
百度网盘/
└── qingniao_backups/
    ├── 2026-01-11/
    │   ├── backup_20260111_020000/
    │   │   ├── qingniao_abu.duckdb.gz
    │   │   ├── qingniao_de.duckdb.gz
    │   │   ├── ...
    │   │   └── backup_manifest.json
    │   └── backup_20260111_140000/
    ├── 2026-01-12/
    └── ...
```

## ⏰ 上传计划建议

### 日常备份（本地）
- **频率**: 每天自动备份
- **保留**: 本地保留7天
- **上传**: 不上传到网盘（节省时间）

### 周备份（本地 + 网盘）
- **频率**: 每周日备份
- **保留**: 本地保留7天，网盘保留1个月
- **上传**: 上传到网盘

### 月备份（归档）
- **频率**: 每月1号备份
- **保留**: 网盘长期保留（1年+）
- **上传**: 必须上传到网盘

## 🔍 验证上传

上传完成后，建议验证：

1. **检查文件数量**
   - 本地备份文件数 = 网盘文件数

2. **检查文件大小**
   - 对比文件大小是否一致

3. **下载测试**
   - 下载一个文件测试是否能正常下载和解压

## 💡 上传技巧

### 1. 分批上传大文件

如果备份文件很大（> 1GB），可以：
- 先上传数据库文件（较小）
- 再上传数据目录（较大）

### 2. 使用断点续传

百度网盘客户端支持断点续传：
- 如果上传中断，可以继续上传
- 不需要重新开始

### 3. 上传时不要关闭电脑

- 确保上传完成后再关闭电脑
- 可以设置电脑不休眠

## 📊 存储空间估算

### 典型备份大小

- **数据库文件（压缩后）**: 约 50-200 MB
- **数据目录（压缩后）**: 约 100-500 MB
- **单次备份总计**: 约 150-700 MB

### 存储需求

- **周备份（4次/月）**: 约 600 MB - 2.8 GB/月
- **月备份（12次/年）**: 约 1.8 GB - 8.4 GB/年
- **建议网盘空间**: 至少 10 GB（免费用户有2TB，完全够用）

## 🔒 安全建议

### 1. 加密敏感备份

如果备份包含敏感信息（API密钥等），建议加密：

```bash
# 使用7zip加密
7z a -p你的密码 backup_encrypted.7z backups/backup_*/
```

然后上传加密后的 `.7z` 文件。

### 2. 访问控制

- 不要分享备份文件夹链接
- 定期检查网盘访问日志
- 使用强密码保护网盘账号

### 3. 多地点备份

- 本地备份 + 百度网盘
- 可以考虑再备份一份到其他云盘（阿里云盘等）

## 🛠️ 故障排除

### 问题1: 上传速度慢

**解决方案**:
- 使用客户端上传（比网页版快）
- 避开网络高峰期
- 检查网络连接

### 问题2: 上传失败

**解决方案**:
- 检查网络连接
- 重新上传
- 分批上传大文件

### 问题3: 文件损坏

**解决方案**:
- 重新上传
- 验证本地备份文件完整性（检查哈希值）

## 📝 备份检查清单

上传前检查：
- [ ] 本地备份已完成
- [ ] 备份文件完整（检查 `backup_manifest.json`）
- [ ] 网盘有足够空间
- [ ] 网络连接正常

上传后检查：
- [ ] 文件数量一致
- [ ] 文件大小一致
- [ ] 可以正常下载
- [ ] 备份清单已上传

## 🔄 定期维护

### 每月检查

1. 检查网盘备份是否完整
2. 删除超过1个月的周备份（保留月备份）
3. 验证最新备份可以正常下载

### 每季度检查

1. 测试恢复流程
2. 验证备份文件完整性
3. 更新备份策略（如需要）
