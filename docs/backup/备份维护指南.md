## 📅 日常维护

### 1. 自动备份（推荐）

设置Windows任务计划程序，每天自动备份：

#### 方法A: 使用脚本（推荐）

```bash
# 以管理员身份运行
scripts/setup_auto_backup.bat
```

这将创建一个每天凌晨2点运行的备份任务。

#### 方法B: 手动创建任务

1. 打开"任务计划程序"
2. 创建基本任务
3. 名称: `QingNiao_AutoBackup`
4. 触发器: 每天 02:00
5. 操作: 运行 `python scripts/backup_data.py`

### 2. 手动备份

需要立即备份时：

```bash
python scripts/backup_data.py
```

### 检查本地备份

1. 登录百度网盘
2. 检查文件数量（应与本地一致）
3. 检查文件大小
4. 下载一个小文件测试

## ⚠️ 故障处理

### 备份失败

**可能原因**:
- 磁盘空间不足
- 文件被占用
- 权限问题

**解决方法**:
1. 检查磁盘空间
2. 关闭可能占用文件的程序
3. 以管理员权限运行

### 上传失败

**可能原因**:
- 网络问题
- 文件太大
- 网盘空间不足

**解决方法**:
1. 检查网络连接
2. 分批上传
3. 清理网盘空间

### 恢复测试

每季度测试一次恢复流程：

1. 从网盘下载备份
2. 解压文件
3. 恢复数据库
4. 验证数据完整性
