# 青鸟系统详细日志使用指南

## 概述

所有程序现在默认启用详细日志输出，日志配置统一在 `config/logging_config.json` 中管理。

## 配置文件

配置文件位置：`config/logging_config.json`

```json
{
  "log_level": "DEBUG",
  "log_dir": "data/logs",
  "retention_days": 90,
  "enable_file_logging": true,
  "enable_console_logging": true,
  "enable_detailed_progress": true,
  "enable_timing": true,
  "enable_performance_metrics": true,
  "console_format": "detailed",
  "file_format": "jsonl",
  "log_process_info": true,
  "log_command_line": true,
  "log_environment": false,
  "log_stderr": true
}
```

### 配置项说明

- `log_level`: 日志级别（DEBUG, INFO, WARNING, ERROR）
- `log_dir`: 日志文件目录
- `retention_days`: 日志保留天数（默认90天）
- `enable_file_logging`: 是否启用文件日志
- `enable_console_logging`: 是否启用控制台日志
- `enable_detailed_progress`: 是否记录详细进度
- `enable_timing`: 是否记录时间统计
- `enable_performance_metrics`: 是否记录性能指标
- `console_format`: 控制台输出格式（simple/detailed）
- `log_process_info`: 是否记录进程信息（PID, CPU, 内存）
- `log_command_line`: 是否记录命令行参数

## 使用方法

### 方法1: 使用 DetailedLogger（推荐）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
import sys
from pathlib import Path

# 添加 src 到路径
SRC = Path(__file__).resolve().parent.parent / 'src'
if str(SRC) not in sys.path:
    sys.path.insert(0, str(SRC))

from detailed_logger import get_detailed_logger

def main():
    logger = get_detailed_logger('my_script')
    
    # 记录启动
    logger.log_startup({'arg1': 'value1'})
    
    try:
        # 记录信息
        logger.info("开始处理数据")
        
        # 记录进度
        total = 100
        for i in range(total):
            if i % 10 == 0:
                logger.progress('process_data', i, total, f"处理中: {i}/{total}")
        
        # 记录操作时间
        logger.start_operation('heavy_computation')
        # ... 执行耗时操作 ...
        logger.end_operation('heavy_computation', success=True)
        
        logger.info("处理完成")
        
    except Exception as e:
        logger.error("处理失败", error=e)
        return 1
    
    finally:
        # 记录结束
        logger.log_shutdown(exit_code=0)
    
    return 0

if __name__ == '__main__':
    sys.exit(main())
```

### 方法2: 使用便捷函数

```python
from detailed_logger import (
    log_info, log_progress, 
    log_start_operation, log_end_operation
)

# 直接使用便捷函数
log_info("处理数据")
log_progress('process', 50, 100, "处理中...")
log_start_operation('computation')
# ... 执行操作 ...

```

### 方法3: 使用 SystemLogger（系统操作）

```python
from system_logger import get_system_logger

logger = get_system_logger()

# 记录信号生成
logger.log_signal_generation(
    signals_count=5,
    timeframe='15m',
    system_name='de',
    current_price=88710.0
)

# 记录交易记录
logger.log_trade_record(
    action='add',
    trade_id=123,
    details={'entry_price': 88710.0}
)

# 记录错误
logger.log_error(
    error_type='APIError',
    error_message='请求失败',
    error_details={'url': 'http://api.example.com'}
)
```

## 日志输出位置

### 文件日志
- 位置：`data/logs/logs_YYYYMMDD.jsonl`
- 格式：JSON Lines（每行一个JSON对象）
- 保留：90天（可配置）

### 控制台日志
- 实时输出到标准输出
- 格式：根据 `console_format` 配置（simple/detailed）
- 包含时间戳、级别、消息、详情

## 日志记录内容

每条日志记录包含：
- `id`: 唯一日志ID（UUID）
- `timestamp`: 时间戳
- `log_type`: 日志类型（conversation, operation等）
- `log_level`: 日志级别
- `operation_type`: 操作类型
- `operation_details`: 操作详情（包含消息、参数等）
- `process_info`: 进程信息（如果启用）
  - `pid`: 进程ID
  - `cpu_percent`: CPU使用率
  - `memory_mb`: 内存使用（MB）
- `command_line`: 命令行参数（如果启用）
- `progress`: 进度信息（如果记录进度）
- `timing`: 时间统计（如果记录时间）

## 最佳实践

1. **所有新脚本都应使用 DetailedLogger**
   - 自动记录启动/结束
   - 自动记录操作时间
   - 自动记录错误和异常

2. **长循环中记录进度**
   ```python
   for i, item in enumerate(items):
       if i % 10 == 0:
           logger.progress('process_items', i, len(items))
   ```

3. **记录关键操作的耗时**
   ```python
   logger.start_operation('api_call')
   result = call_api()
   logger.end_operation('api_call', success=True, details={'result_count': len(result)})
   ```

4. **异常处理时记录错误**
   ```python
   try:
       risky_operation()
   except Exception as e:
       logger.error("操作失败", error=e, details={'context': 'value'})
   ```

5. **使用系统日志记录业务操作**
   ```python
   # 交易记录、信号生成等使用 SystemLogger
   system_logger.log_trade_record(action='add', ...)
   ```

## 日志查看

### 查看今日日志
```bash
# Windows PowerShell
Get-Content data\logs\logs_$(Get-Date -Format 'yyyyMMdd').jsonl | ConvertFrom-Json | Select-Object -First 10

# Linux/macOS
cat data/logs/logs_$(date +%Y%m%d).jsonl | head -n 10 | jq .
```

### 搜索日志
```python
from file_logger import get_file_logger

logger = get_file_logger()
results = logger.search(query='error', limit=10)
for entry in results:
    print(entry)
```

### 统计信息
```python
from file_logger import get_file_logger

logger = get_file_logger()
stats = logger.get_stats()
print(f"总文件数: {stats['total_files']}")
print(f"总日志数: {stats['total_entries']}")
print(f"最旧日期: {stats['oldest_date']}")
print(f"最新日期: {stats['newest_date']}")
```

## 维护

### 清理旧日志
日志系统会自动清理超过保留期限的日志（默认90天）。

手动清理：
```python
from file_logger import get_file_logger

logger = get_file_logger()
deleted = logger.cleanup_old_logs(days=90)
print(f"删除了 {deleted} 个旧日志文件")
```

### 压缩旧日志
自动压缩1个月之前的日志文件：
```python
from file_logger import get_file_logger

logger = get_file_logger()
compressed = logger.compress_old_logs()
print(f"压缩了 {compressed} 个日志文件")
```

## 故障排查

### 日志文件不生成
1. 检查 `config/logging_config.json` 是否存在
2. 检查 `enable_file_logging` 是否为 `true`
3. 检查 `data/logs` 目录是否可写

### 控制台无输出
1. 检查 `enable_console_logging` 是否为 `true`
2. 检查日志级别是否合适（DEBUG/INFO）

### 进程信息缺失
1. 需要安装 `psutil`（可选）：`pip install psutil`
2. 如果未安装，进程信息将不记录，但日志系统仍正常工作
