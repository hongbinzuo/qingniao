#### 2. 入场点逻辑（待优化）

**当前问题**:
```python
entry_price = current_price  # 直接用当前价格
```

**问题**:
- 没有等待回调确认
- 没有判断是否是回调结束
- 无法区分H1/H2/H3

**改进方向**:
- 等待回调确认（如突破前高）
- 等待关键K线（如Bullish Engulfing）
- 判断回调类型（H1/H2/H3）

#### 3. 止损逻辑（待优化）

**当前问题**:
```python
stop_loss = min(recent_lows)  # 只是简单取最低点
```

**问题**:
- 没有判断是否是回调的低点
- 可能是正常波动，不是H1/H2的回调结构

**改进方向**:
- 使用摆动点（swing low/high）
- 基于实际回调结构
- 添加缓冲（避免被正常波动扫掉）

#### 4. 止盈逻辑（待优化）

**当前问题**:
```python
take_profit_1_pct = stop_loss_pct * 1.5  # 固定1.5:1 RR
```

**问题**:
- 没有基于实际阻力位
- 不考虑H1/H2/H3的不同目标位

**改进方向**:
- 基于实际阻力位（前高、阻力位）
- 考虑H1/H2/H3的不同目标
- 动态调整RR比例

## 已创建的优化工具

### 1. `src/abu/signal_quality_enhancer.py`（新建）

**功能**:
- `find_swing_points()`: 寻找摆动点（swing high/low）
- `find_recent_support_resistance()`: 找到最近的支撑和阻力位
- `calculate_improved_stop_loss()`: 改进的止损计算
- `calculate_improved_take_profit()`: 改进的止盈计算
- `enhance_signal_prices()`: 增强信号的价格设置

**使用方式**:
```python
from abu.signal_quality_enhancer import enhance_signal_prices

enhanced_signal = enhance_signal_prices(
    signal, klines,
    use_swing_points=True,
    use_resistance=True
)
```
