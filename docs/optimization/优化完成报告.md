## 优化效果

### 改进前

**止损逻辑**：
```python
stop_loss = min(recent_lows)  # 简单取最低点
```

**止盈逻辑**：
```python
take_profit_1 = entry_price * (1 + stop_loss_pct * 1.5)  # 固定1.5:1 RR
```

**问题**：
- 止损可能不是回调低点
- 止盈没有考虑实际阻力位
- 容易被正常波动扫掉

### 改进后

**止损逻辑**：
```python
# 使用摆动点
swing_low, _ = find_swing_points(klines, window=5)
stop_loss = swing_low * 0.999  # 摆动低点下方0.1%缓冲
```

**止盈逻辑**：
```python
# 基于实际阻力位
levels = find_recent_support_resistance(klines, lookback=50)
resistance = levels.get('resistance')
take_profit_1 = resistance * 0.998  # 阻力位下方0.2%缓冲
```

**优势**：
- 止损基于实际结构（摆动点）
- 止盈基于实际阻力位
- 添加缓冲避免被扫
- 更符合实际交易逻辑
