## 三、技术实现细节

### 3.1 增强版混合匹配器架构

```
EnhancedHybridMatcher
├── UnifiedPatternLibrary (统一模式库)
├── AsyncPatternMatcher (异步匹配器)
├── MultiSourceFusion (多源融合算法)
└── HybridVisionPatternMatcher (可选，视觉验证)
```

**工作流程**：
1. 使用统一模式库进行多源异步匹配
2. 应用多源融合算法计算融合置信度
3. （可选）使用AI视觉验证Top N结果
4. 综合评分，返回最终结果

### 3.2 匹配策略

**Fast策略**：
- 只使用Gemini Flash数据源
- 算法匹配，不使用视觉验证
- 最快速度，适合实时扫描

**Balanced策略**：
- 使用Gemini Flash + Cursor AI
- 算法筛选 + AI视觉验证Top 10
- 平衡速度和精度

**Comprehensive策略**（默认）：
- 使用所有三个数据源
- 算法筛选 + AI视觉验证 + 规则验证
- 最高精度，适合信号生成

### 3.3 性能优化

**异步匹配**：
- 并行查询三个数据源
- 使用线程池管理并发
- 性能提升：约2-3倍

**多源融合**：
- 加权平均：根据数据源权重
- 一致性奖励：多源匹配时提升置信度
- 自动分组：按模式类型分组融合
