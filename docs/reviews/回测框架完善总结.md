## 二、使用方法

### 2.1 回测单个交易计划

```bash
python scripts/backtest_trading_plan.py trading_signals/vision_enhanced_plan_20260114_110937.md
```

### 2.2 自动化批量回测

```bash
# 回测所有交易计划
python scripts/auto_backtest_trading_plans.py

# 限制数量
python scripts/auto_backtest_trading_plans.py --limit 5
```

### 2.3 定时任务（Windows）

1. 打开"任务计划程序"
2. 创建基本任务
3. 触发器：每天指定时间
4. 操作：启动程序 `scripts/auto_backtest_daily.bat`

### 2.4 定时任务（Linux/macOS）

```bash
# 添加到crontab
0 2 * * * /path/to/qingniao/scripts/auto_backtest_daily.sh
```

## 三、回测逻辑

### 3.1 保本止损

1. **初始**: 使用信号中的止损价
2. **触及止盈1**: 止损移动到入场价（保本）
3. **触及保本止损**: 状态为"部分止盈"（`partial_tp`）

### 3.2 信号验证

- ✅ 做多止损应在入场价下方
- ✅ 做空止损应在入场价上方
- ✅ 入场价未到但先到止盈1，信号无效

### 3.3 账户管理

- **手续费**: 开仓和平仓各0.05%（默认）
- **滑点**: 买入+0.02%，卖出-0.02%（默认）
- **仓位**: 单笔10%总权益（默认）

## 四、性能指标

- **总收益率**: 总收益百分比
- **最大回撤**: 权益曲线最大跌幅
- **Sharpe比率**: 风险调整后收益
- **盈亏比**: 总盈利/总亏损
- **胜率**: 盈利交易/总交易
- **平均盈利/亏损**: 盈利和亏损的平均值

## 五、输出文件

### 5.1 单文件回测

- `trading_signals/backtest_report_*.md` - Markdown报告

### 5.2 批量回测

- `trading_signals/backtest_reports/backtest_*.md` - 每个计划的报告
- `trading_signals/backtest_reports/backtest_*.json` - JSON结果
- `trading_signals/backtest_reports/backtest_summary_*.md` - 汇总报告
