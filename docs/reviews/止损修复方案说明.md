# DOGE等小价格币种止损修复方案

**修复时间**: 2026-01-14  
**问题**: DOGE、BREV等小价格币种（< $1）的止损等于入场价

---

## 一、问题分析

### 1.1 问题现象

- **DOGE**: 入场价 $0.14，止损 $0.14（等于入场价）
- **BREV**: 入场价 $0.33，止损 $0.33（等于入场价）
- **结果**: 风险为0，盈亏比无法计算，信号不可交易

### 1.2 根本原因

1. **精度问题**: 价格极小的币种（< $1），在计算止损时可能出现精度丢失
2. **最近低点/高点**: 如果最近10根K线的最低点/最高点等于或非常接近当前价格
3. **计算逻辑**: 原逻辑使用`min(recent_lows)`可能返回等于入场价的值

---

## 二、修复方案

### 2.1 核心修复逻辑

```python
# 1. 检测小价格币种
is_small_price = entry_price < 1.0

# 2. 计算止损时，对于小价格币种特殊处理
if is_small_price:
    # 至少0.5%的绝对距离
    min_absolute_distance = entry_price * 0.005  # 0.5%
    min_stop_absolute = entry_price - min_absolute_distance
    stop_loss = min(stop_loss, min_stop_absolute)

# 3. 最终验证：止损必须明显低于入场价
if stop_loss >= entry_price * 0.999:  # 如果止损太接近入场价（误差<0.1%）
    # 强制设置止损为入场价的(1 - min_stop_distance_pct)
    stop_loss = entry_price * (1 - min_stop_distance_pct)

# 4. 风险验证：确保风险>0
risk = entry_price - stop_loss
if risk <= 0 or risk < entry_price * 0.001:  # 风险太小（<0.1%）
    # 重新计算止损
    stop_loss = entry_price * (1 - min_stop_distance_pct)
    risk = entry_price - stop_loss
```

### 2.2 修复要点

1. **小价格检测**: `entry_price < 1.0`
2. **绝对距离保证**: 至少0.5%的绝对距离
3. **最终验证**: 止损必须明显低于入场价（误差<0.1%）
4. **风险验证**: 确保风险>0且>0.1%
