**关键算法**：
```python
# 加权平均
weighted_avg = sum(confidence * weight) / sum(weight)

# 一致性奖励
consistency_bonus = min((source_count - 1) * bonus_per_source, max_bonus)

# 最终置信度
final_confidence = weighted_avg * (1 + consistency_bonus)
```

## 三、技术实现细节

### 3.1 统一模式数据结构

```python
@dataclass
class UnifiedPattern:
    pattern_id: str          # 统一ID
    source: str              # 数据源
    original_id: Any         # 原始ID
    pattern_name: str        # 模式名称
    pattern_type: str        # 模式类型
    direction: str           # 方向
    confidence: float        # 置信度
    structured_features: Dict  # 标准化特征
    raw_data: Dict          # 原始数据
```

### 3.2 特征标准化

**Gemini Flash特征标准化**：
- 提取`price_action_behavior`
- 提取`market_conditions`
- 提取`trading_signals`

**Cursor AI特征标准化**：
- 提取`kline_features`
- 提取`price_levels`
- 提取`pattern_structure`
- 提取`trading_signals`

**Brooks规则标准化**：
- 提取`trading_rules`
- 提取`key_concepts`
- 提取`content_summary`

### 3.3 多源融合算法

**步骤**：
1. 加权平均：根据数据源权重计算加权平均置信度
2. 一致性奖励：多个源匹配到相似模式时，提升置信度
3. 结果排序：按融合置信度排序

**一致性奖励规则**：
- 2个源匹配：提升10%
- 3个源匹配：提升20%（最大）
