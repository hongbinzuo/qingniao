# 自动回测集成说明

**实现时间**: 2026-01-14  
**功能**: 交易计划生成后自动回测，记录结果，检测问题并反馈

---

## 一、功能概述

### 1.1 自动回测流程

```
交易计划生成 → 自动回测 → 结果记录 → 问题检测 → 反馈输出
```

### 1.2 核心功能

1. **自动回测**
   - 交易计划生成后自动运行回测
   - 无需手动操作
   - 支持所有交易计划格式

2. **结果记录**
   - 自动保存回测结果（JSON + Markdown）
   - 记录所有性能指标
   - 记录失败信号详情

3. **问题检测**
   - 自动检测警告（胜率、回撤、盈亏比等）
   - 自动检测严重问题（所有信号失败、收益率严重为负等）
   - 统计失败原因

4. **及时反馈**
   - 控制台输出反馈信息
   - 标记严重问题
   - 提供详细统计

---

## 二、问题检测阈值

### 2.1 警告阈值

| 指标 | 阈值 | 说明 |
|------|------|------|
| **最低胜率** | 40% | 低于此值发出警告 |
| **最大回撤** | 30% | 超过此值发出警告 |
| **最低盈亏比** | 1.2 | 低于此值发出警告 |
| **最低Sharpe比率** | 0.5 | 低于此值发出警告 |

### 2.2 严重问题检测

1. **所有信号失败**
   - 检测：如果所有信号回测失败
   - 反馈：统计失败原因并报告

2. **收益率严重为负**
   - 检测：总收益率 < -20%
   - 反馈：标记为严重问题

3. **回撤过大**
   - 检测：最大回撤 > 50%
   - 反馈：标记为严重问题

4. **胜率极低**
   - 检测：交易数 >= 10 且胜率 < 30%
   - 反馈：标记为严重问题

## 三、使用方式

### 3.1 自动集成

所有交易计划生成脚本已自动集成：

- `scripts/test_top10_vision_enhanced.py` - 视觉增强版本
- `scripts/test_top10_pattern_only.py` - 纯模式匹配版本

**无需额外操作**，生成交易计划后自动回测。

### 3.2 输出文件

回测结果自动保存到：
- **JSON格式**: `outputs/backtest_results/backtest_{plan_name}_{timestamp}.json`
- **Markdown格式**: `outputs/backtest_results/backtest_{plan_name}_{timestamp}.md`

### 3.3 反馈输出

控制台自动输出：
- 信号统计
- 性能指标
- 警告信息
- 严重问题

## 六、配置选项

### 6.1 回测参数

可在脚本中配置：

```python
backtest_integration = AutoBacktestIntegration(
    initial_balance=10000.0,  # 初始资金
    fee_bps=5.0,              # 手续费基点
    slippage_bps=2.0,         # 滑点基点
    position_size_pct=0.1     # 仓位百分比
)
```

### 6.2 问题检测阈值

可在 `src/abu/auto_backtest_integration.py` 中修改：

```python
self.warning_thresholds = {
    'min_win_rate': 0.40,      # 最低胜率
    'max_drawdown': 0.30,      # 最大回撤
    'min_profit_factor': 1.2,  # 最低盈亏比
    'min_sharpe': 0.5,         # 最低Sharpe比率
}
```
